# Agent Note：青木原生会话中的创作方法

Status: implemented

[English](2026-09-11-qingmu-creative-methods.md) | 中文

## 问题

方法名称或局部模板不足以支撑导演流程。声音、表演、连续性和调度参考必须到达模型。上游对说话人数和运镜数量的假设也可能与项目剧本和导演决定冲突。

## 决策

青木预设使用原生技能发现和加载，携带 cinematic-director 与 ai-visual-director 方法。作用域内资料读取器校验清单路径与哈希，明确分页，分别记录上游和适配后来源。适配保留创作方法，移除有效指令和质检表中的说话人数、动作数量、运镜数量及对白长度定额。历史案例与模型估计仅供参考。剧本和导演设计决定如何创作；能力不足须明确执行替代方案，不能静默简化作品。

## 考虑过的替代方案

启动时注入整个方法库消耗上下文，却不能确保正确使用关联参考。再造技能注册表会重复 DSH 能力。只摘录部分句子会丢失方法及关联依赖。

## 影响

真实 Loader 和 Agent 循环测试验证技能目录、完整方法与参考进入后续模型请求，以及会话隔离。资料测试覆盖分页、来源完整性和拒绝路径。这些检查证明方法可读取，不代表真实模型已完成创作、设计已保存到项目、付费生成质量达标或用户认可。[来源清单](../../../../packages/experimental/qingmu-web/agent-presets/qingmu-director/skills/sources.json) 标明版本和排除的二进制案例媒体。
