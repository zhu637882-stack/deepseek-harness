# Agent Note: 青木按项目绑定素材连接

Status: implemented

[English](2026-09-10-qingmu-material-connection.md) | 中文

## Problem

引用视频的素材准备需要 DashScope Key，而本地 production 绑定同时授予历史固定预算范围。准备引用文件应能独立工作，不启用该生产权限，也不向无关服务共享凭证。

## Decision

专属 Python 装配接受一个可选的原生项目/剧集连接。它验证私有文件中的字面量 Key，仅为现有引用预览和临时素材服务复制 Settings。启动时固定项目所有者，执行时与镜头范围一起检查，包括事务内复核。API 共享 Settings、Worker 环境和 ProviderGate 保持关闭付费。此模式与 production/fixture 配置互斥；实例停止后可通过命令连接或断开，不写业务数据、不发外部请求。

精确字节、Key 指纹、模型、有效期、上传意图和未知结果处理归现有上传服务。报价校验和包含全局生成可用状态。新任务在写队列前拒绝关闭的付费开关；已有回执仍可读取。不新增表、Worker、队列或模型工具。

## Alternatives considered

**全局加载 production 环境。** 这会暴露无关凭证，并把免费上传与过时预算耦合。

**另建上传管线。** 这会重复现有回执、有效期和来源核验逻辑。

## Consequences

凭证只留在进程内的一项素材能力中。配置绑定探测到的 Key 指纹；Key 改变后启动失败，需显式重新连接。轮换后旧 Key 回执不再复用。断开不依赖项目数据库，重复操作可恢复中断的审计完成写入。中断的审计可能保留 pending 记录；最终配置和最新 completed 回执共同证明恢复后的状态。临时 URL 不属于永久存储，其存在不证明模型已调用。连接测试使用真实 Writer 路由与模拟 OSS，验证越界拒绝、共享权限不变，以及密钥轮换、停止实例的连接/断开、范围缺失与审计写入失败。真实付费模型质量不在这些检查范围内。
