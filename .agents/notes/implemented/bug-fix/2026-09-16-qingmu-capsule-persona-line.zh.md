# Agent Note: 青木经验胶囊的提示词行

Status: implemented

[English](2026-09-16-qingmu-capsule-persona-line.md) | 中文

## 问题

导演角色提示词会注入本次会话应遵守的、已人工审核的经验胶囊。项目没有已审核胶囊时，注入文本为空，角色提示词因此以空行结尾：模型收到一个尾部空段落，已提交的角色快照也记录了它。非空文本同样需要独占一行，因此把占位符改为内联之前，必须先决定由谁提供换行。

## 决策

换行由 `renderExperienceCapsulesBlock` 负责。没有胶囊需要渲染时返回 `''`；否则返回以单个 `\n` 开头的文本块。预设把 `{{experience_capsules}}` 内联放在角色提示词最后一段末尾，因此空存储不插入任何内容，有胶囊时另起一行。该块两端都不追加空行。

## 考虑过的替代方案

**占位符仍单独占一行**被否决：没有胶囊时总会留下一个空行，而没有已审核胶囊的项目正不该发送这个空行。

**渲染角色提示词时统一去除空行**被否决：这种裁剪会影响所有预设作者，掩盖真实段落分隔，并把决定权移离唯一知道是否存在文本块的调用点。

**保留文本块尾部换行并把占位符内联**被否决：有胶囊时该段会多出一个尾部换行，与所报缺陷正好相反。

## 后果

没有胶囊的项目，其角色提示词文本与已提交快照逐字节一致；每个胶囊块另起一行且没有尾部空行。该规则由一个函数及其 `@returns` 合同承载，不再依赖预设中的空白，因此后续把占位符移位的预设编辑必须保持内联位置，或连同换行一起移动。本次渲染改动不改变选取哪些胶囊、其顺序或行数上限。
