# Agent Note: 青木共用拍摄执行提示词

Status: implemented

[English](2026-09-15-qingmu-shared-execution-prompt.md) | 中文

## 问题

批量准备选择引用后，把整份保存设计拼进视频请求。《下班》的成功基线另有项目专用脚本，具体整理表演、时间、摄影和声音。两部作品都使用批量队列与同一供应商路线；仅凭并发不能解释质量差异。

## 决策

原生导演根据当前设计与实际参考编写 executionPrompt。单镜工具和批量组件共用浏览器可用的 assembleReferencePrompt；Writer 提供 executionSuffix，保留逐字对白、视觉媒介与画面文字范围。结果仍保存为普通提示词片段，不另建广告路线、供应商接口或数据库。浏览器构建仅允许此纯函数子入口，后端适配器仍不进入浏览器。来源哈希包含新后缀，尚未提交的旧稿需要核对当前来源。审片从实际冻结请求读取拍摄描述与对白。场次规划将连续表演保留在生成段内，段内切点写到 coveragePlan。

此决定扩展[引用路由](2026-09-10-qingmu-reference-director-routing.zh.md)：已保存及明确手工编写的 promptParts 仍可编辑；所有新自动准备必须编写执行描述。此前单镜参数可省略，导致静默复制完整来源；共用装配函数与原生工具现已按批量相同规则拒绝这一缺失。

## 考虑的替代方案

**给整份文档追加更多禁止项。** 无法补足动作时点、倾听反应或空间过渡。

**继续项目专用脚本。** 可以修好一个例子，却不能改善客户日常流程。

## 影响

现有准备模型回合承担更多创作，不增加视频调用或客户操作步骤。来源一致不代表语义正确；导演仍可能遗漏或误解细节，实际媒体仍需审看。已有视频与选用结果不变。原生组合、批量和后端测试覆盖共用装配、逐字对白、缺失执行稿、来源保留及冻结请求审片，不代表新成片已验收。

已有布局与机位时，共用准备说明要求调用现有场景预览，结合实际参考核对取景与机位相关的左右关系。没有人物体块时不能声称预览核实了演员站位。这是导演准备方法，不新增批准门禁，也不承诺生成模型必然遵从。

受控重拍另外暴露输入遗漏：批量上下文有素材目录，却没有各镜当前绑定。现补入已保存引用的精确版本，导演先核对实际使用版本，再考虑替代候选。客户端组合测试覆盖保留修正版场景引用，同时验证旧执行文字不被复制成当前指令。同次试跑还在未解决来源警告后输出了假设修好的可采用方案。现明确这种情况只交核查结论，不同时交可采用的shots区块。


候选观察复用原队列，视频与音频观察提示词不再包含剧本、预期台词或导演设计。Writer 把比较要求单独冻结到任务，随有来源的观察报告提供给导演，从输入上分开观察和答案。观察不是验收，模型擅自输出的逐项结论不能成为通过。原生导演通过 `qingmu_read_reference_video_candidates` 的 `reviewPage` 逐个读取精确候选报告，与原生成请求及当前设计比较。普通评论与音画观察分别提供，无评论不再意味着无音频审查；范围或 SHA 不符保留为不可用。网页显示实际听写与观察，单镜整理也改用批量相同的执行说明。未新增队列、生成器、选用动作或自动批准。

读取适配器拥有浏览器可用的 `native-video-review` 投影，驾驶舱直接共用；打包仅放行这个纯子路径，Host 实现仍不进入浏览器。测试走真实导演工具组合，覆盖评论为空但报告存在、报告缺失/不可用/版本不符、独立听写、不确定判断及只读恢复。Writer 测试验证预期内容没有进入排队的供应商请求，同时保存在不可变比较上下文中。实际样片仍需核查：独立观察也可能出错，测试通过或报告完成不能证明视频质量合格。

登记后的 Take 与原候选使用不同素材编号。Writer 现在按同一镜头与视频 SHA 读取既有观察，保留原审片素材编号及冻结比较要求。这样可以恢复已付费取得的证据，不会混入其他镜头或不同视频的报告。

真实导演读取修复后的报告后，仍把模型听写中的额外语句写成确定事实。共用准备与候选读取指导现要求标明模型观察是报告记载；拿报告与文字对照不能独立核实原片。疑似额外对白仍待回放听审。这只调整证据表达，不改变选用权或生成行为。

系统回归覆盖无对白动作、画外说话、产品特写与重复台词，经过原生保存与适配器预览；批量回归核对同一装配函数及提交路径。带旧自动完整来源标记的草稿，即使来源编号一致也回到准备；手工稿与当前执行稿仍可复用。分镜交稿示例明确给出有时间的因果动作阶段，采用时完整保留；素材创作要求独立道具使用纯色背景，并与有意设计的场景交互状态图区分。这些规则适用于后续项目，不增加客户设置或逐项目补丁。只读检查两个已有广告项目共72镜，发现历史输入大多已过期、动作多为一条总述；音频开关与说话人音色绑定并不能解释已报告的听感缺陷。没有替换旧媒体。提示词和传输测试不能证明生成的动作、人物、声音及连续性已经合格。
