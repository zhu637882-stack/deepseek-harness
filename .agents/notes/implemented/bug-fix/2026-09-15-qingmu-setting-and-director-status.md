# Scene identity and director status

Status: implemented

English | [中文](2026-09-15-qingmu-setting-and-director-status.zh.md)

The imperial-study candidate retained room geometry but reduced its identity to a place name. Local prop repairs preserved the same plain furnishings. Shared asset authoring now translates the source location, occupant status and maintenance state into visible finishes and fixed decoration, distinguishes empty staging from empty architecture, and revisits the whole setting after local repairs. It does not impose palace decoration on unrelated projects or invent screenplay facts.

Scene planning also displayed an unselected shot-edit session alongside a running independent scene-authoring request. The details now identify their saved-shot scope, direct new projects to scene design and save, and remove static claims about film-wide prompt readiness and the obsolete product name. No session activation, generation or adoption behavior changes.

The existing asset request snapshot exercises the shared prompt; scene-planning tests cover creation, saved-shot binding and recovery. Actual generated scene identity remains a visual judgment. The production-design section of [Visual Media Analysis Expert](https://prompts.chat/prompts/cmmx3l25d001bil046oqvr24j_visual-media-analysis-expert-agent-role) informed only the link between visible materials and world context; its exhaustive checklists, metadata guesses and workflow rules were not adopted.

Voice directions must translate known age into audible character traits, and period props into material and usable construction. The media library labels full auditions and derived references separately. Shared actor-profile persistence is verified in the Writer API tests for creation, revision, omission and clearing without replacing enrolled audio.

The character, scene and prop methods now describe visible period construction, social identity and makeup, separating stable appearance from temporary story state. The immutable/mutable split and compact reference descriptions were independently adapted from [director-skills](https://github.com/0xhughs/director-skills), `character-location-prop-bible` and `cinematic-image-prompting`, commit `35ca0a2b4cd55b0668aa9ea0f40273324b774bb4` (MIT, Copyright 2026 0xhughs). The new production-design native skill bundles both pinned upstream entries, every linked reference/template and their MIT license. Its entry maps outputs to Qingmu fields, and the shared asset request loads it before authoring. No scripts or model clients were installed. prompts.chat remains a research source, not a live native-generation dependency.

The media preview now offers explicit manual deletion and restoration. Deleted media leaves the default reference catalog but its files, hashes and generation history remain recoverable. Writer binds each mutation to project ownership and the exact asset hash; selected or saved-design inputs remain protected, and deleted references cannot enter new image/video requests. Catalog changes refresh open reference pickers without replacing unsaved design text. The user alone chooses versions; no age-, quality- or date-based cleanup runs automatically.

Reusable prop methods and the shared authoring prompt also distinguish net weight, package dimensions and physical object dimensions, preserve source confidence and propagate consistent scale into hand-held and container relationships. Exact vendor measurements remain a source question, not an inference from image pixels.
