# Agent Note: 青木素材核对与审看导航

Status: implemented

[English](2026-09-10-qingmu-workspace-review-links.md) | 中文

## Problem

私有参考素材需要显示图片，方便比较人物与场景。交付阻塞只有能定位到相关镜头并返回审看工作区，才是可操作的信息。

## Decision

素材卡片处于可视区附近时复用认证预览钩子。私有缩略图同时最多读取两份，离开后撤销读取并释放完整图片。公开图片和显式音色预览不占用这些槽位。读取失败保留占位和已有详情重试。精简交付行显示返回的阻塞数量，未选视频时优先提示选择候选，再处理后续交接检查；显式按钮沿已有导航保护定位到本镜审看。

## Alternatives considered

**公开媒体地址或新缩略图服务。** 已有受限预览足以覆盖这个小型图片库，无需新增存储或端点。

**另建交付问题面板。** 现有逐镜条目已有权威阻塞清单，可直接承载导航操作。

## Consequences

预览和导航不能采用视频、批准内容或调用生成。原媒体与 Writer 数据保持不变。本地导入视频的来源登记仍属于独立工作。

## Testing

客户端测试覆盖私有图片延迟读取、详情重试、准确镜头导航和采用状态保留。运行检查覆盖真实项目图片、交付至拍摄导航、桌面与手机宽度。这些检查证明界面行为，不代表创意验收。
