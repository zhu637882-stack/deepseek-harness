# Agent Note: 批量补充要求恢复

Status: implemented

[English](2026-09-15-batch-notes-recovery.md) | 中文

## Problem

刷新恢复了原生整集候选，却丢失操作者的补充要求，后续改稿或准备因此使用了不同输入。

## Decision

现有输入按项目与剧集保存至浏览器本地存储，重新挂载时恢复。存储失败时保留当前可用输入并明确提示未保存。恢复不会触发生成或采用。

## Alternatives considered

**要求操作者重填。** 损害任务恢复并丢失创作约束。

**新增后端指令资源。** 这个本地编辑字段复用现有浏览器草稿方式即可。

## Consequences

7项批量组件测试通过，包括重新挂载恢复与剧集隔离。本地浏览器恢复不代表跨设备同步。
