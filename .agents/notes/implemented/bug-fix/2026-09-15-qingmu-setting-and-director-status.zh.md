# 场景身份与导演状态

Status: implemented

[English](2026-09-15-qingmu-setting-and-director-status.md) | 中文

御书房候选保留了空间几何，却把地点身份缩成一个名称；局部道具返修又沿用了普通陈设。共用素材创作现在要求把来源地点、使用者身份与维护状态落实到可见饰面和固定装饰，区分空场与空房，并在局部返修后重新核对整体环境。不向其他项目套用宫殿装饰，不虚构剧本事实。

分镜页同时展示运行中的独立场次创作与未选择的单镜修改会话。详情现明确只说明已保存镜头的修改连接，新项目先完成场次设计并保存；删除静态的整片提示词就绪断言和旧产品名称。不改变会话启动、生成或采用行为。

现有素材请求快照覆盖共用提示词；分镜测试覆盖创建、已保存镜头绑定与恢复。生成场景的身份仍须实际审图。[Visual Media Analysis Expert](https://prompts.chat/prompts/cmmx3l25d001bil046oqvr24j_visual-media-analysis-expert-agent-role) 的美术部分仅用于参考可见材质与世界设定的关联；未采用其繁复清单、元数据猜测或工作流规则。

声音设计将已知年龄转为可听见的人物特征，道具将年代转为材料与可用结构；素材库分别标明完整试听和派生参考。Writer API 测试验证声音设计在新建、修订、省略及清空时同步到人物档案，同时保留已注册声音。

人物、场景和道具方法补充了可见的时代构造、身份与妆发依据，区分稳定外观和剧情中的临时状态。固定/可变特征及精简参考描述的方法独立适配自 [director-skills](https://github.com/0xhughs/director-skills) 的 `character-location-prop-bible`、`cinematic-image-prompting`，提交 `35ca0a2b4cd55b0668aa9ea0f40273324b774bb4`（MIT，Copyright 2026 0xhughs）。新增原生 production-design 技能，内含两个固定版本的上游入口、所有关联参考/模板及 MIT 许可证。入口将输出映射到青木字段，共用素材请求在设计前加载。不安装脚本或模型客户端。prompts.chat 是研究来源，不是原生生成时在线调用的依赖。

素材预览增加明确的手动删除与恢复。删除后退出默认参考目录，文件、哈希及生成历史仍可恢复。Writer 对每次操作核验项目权限与素材版本；采用中或已保存设计引用的素材受保护，已删除参考不能进入新的图片/视频请求。目录变化同步刷新已展开的参考选择器，不替换未保存的设计文字。版本由用户自行选择，不按时间、质量或版本先后自动清理。

共用道具方法与素材设计请求还区分净重、包装尺寸和实体尺寸，保留尺寸来源与确定性，并把同一尺度传入手持和容器关系；厂家实测尺寸仍需来源证据，不能从图片像素猜出。

素材库变化同时刷新生成进度和参考选择器。已删除结果退出当前生成列表；恢复结果沿用原任务，不再次生成。未保存的设计文字保留。

原生设计暴露了另一处不一致：保留道具的画面描述遗漏了新增身份尺寸，布局体块的支承高度也不统一。共用美术方法现在区分保留图片与同步完整描述；场景方法在构图预览前核对地面和支承面、薄部件、旋转边界与真实开口。预览可渲染不代表物理关系通过。

素材重新设计区分已确认身份与被否定的旧方案。人物方法将明确的面部审美、服装变化与听觉年龄落实到实际生成字段；场景方法先设计建筑结构，再处理饰面与家具。生成成功不代表画面或声音合格，仍须审看试听。同源音色片段收在素材库折叠区，不与完整试听并列成额外音色。

默认素材设计将创作补充视为可选偏好，从原始资料和剧本主动设计外观、结构、尺度与听觉身份。原生局部更新只有在主体设定未变时才可继承旧画面描述，单独修改声音仍受支持。候选绑定提交时的补充内容，后续编辑不能悄悄改变其依据。空补充入口测试只验证输入传递，不代表媒体质量通过。

真实空补充回归暴露照抄已存设计。共用美术方法与消费者现区分设计复核与导出 JSON，保存状态不表示创作认可。媒体质量仍未验收。

素材设计对已保存工作稿先传实体与引用索引，本机未保存修改仍传完整正文。导演读取工具明确区分保存状态与创作认可。默认先按电影图片提示词方法做设计，再维护连续性，不把未复核工作稿整体冻结。空补充实际行为仍需运行复测。

素材设计主操作使用 asset-design-from-script：读取工具提供实体、引用与空间锚点，不注入旧设计正文。改进上稿与下游创作仍读取完整已存设计。两个操作都不修改现有媒体或授予创作认可。此次调整源于真实复测：只加来源标签仍然沿用原人物和场景提示词。

默认素材设计将专项美术方法归回现有技能，入口不再重复整套细则。production-design 先把待定建议发展为明确的选角、服化道和建筑选择，再去掉人物与地点名称检查具体描述是否成立，交付简短设计成果及可消费字段；创作补充仍为可选。保存、引用和生成链路保持原有实现。本次移除入口3550字重复指令；真实创作结果仍须复核。
