# 场景身份与导演状态

Status: implemented

[English](2026-09-15-qingmu-setting-and-director-status.md) | 中文

御书房候选保留了空间几何，却把地点身份缩成一个名称；局部道具返修又沿用了普通陈设。共用素材创作现在要求把来源地点、使用者身份与维护状态落实到可见饰面和固定装饰，区分空场与空房，并在局部返修后重新核对整体环境。不向其他项目套用宫殿装饰，不虚构剧本事实。

分镜页同时展示运行中的独立场次创作与未选择的单镜修改会话。详情现明确只说明已保存镜头的修改连接，新项目先完成场次设计并保存；删除静态的整片提示词就绪断言和旧产品名称。不改变会话启动、生成或采用行为。

现有素材请求快照覆盖共用提示词；分镜测试覆盖创建、已保存镜头绑定与恢复。生成场景的身份仍须实际审图。[Visual Media Analysis Expert](https://prompts.chat/prompts/cmmx3l25d001bil046oqvr24j_visual-media-analysis-expert-agent-role) 的美术部分仅用于参考可见材质与世界设定的关联；未采用其繁复清单、元数据猜测或工作流规则。

声音设计将已知年龄转为可听见的人物特征，道具将年代转为材料与可用结构；素材库分别标明完整试听和派生参考。Writer API 测试验证声音设计在新建、修订、省略及清空时同步到人物档案，同时保留已注册声音。
