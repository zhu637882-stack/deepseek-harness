# Agent Note：青木批量导演协调

Status: implemented

[English](2026-09-15-qingmu-batch-director-reconciliation.md) | 中文

## Problem

批量写作会话只有分集范围，旧视频观察工具却要求选中单镜。来源矛盾只能列出问题，采用流程无法先保存导演修订，再装配视频草稿。

## Decision

原候选读取工具接受当前创作分集请求，并核对镜头归属。批量候选可为本次待准备镜头提供可选 `directorRepairs`。原采用按钮先校验完整方案，通过普通场次规划接口按顺序版本保存修订，再重新读取来源，复用单镜提示词装配。

## Alternatives considered

逐镜手工搬运修订会将同一断点留给下次批量。让模型直接写入会绕开写作会话的提案与采用边界。现有规划回执和单镜接口足以承担这些操作，无需另建批量数据库或生成服务。

## Consequences

回执状态不明时不再次保存。沿用原方案与来源快照继续时，先恢复已提交修订，再处理后续；刷新页面后来源已变则重新形成协调方案。已有候选与逐字对白保留。真实 Loader 测试覆盖无单镜绑定的批量审片读取及分集隔离。批量测试覆盖最新来源装配、顺序保存、回执丢失和无效方案。这些验证证明传输与准备行为，不代表生成影片的音画验收。
