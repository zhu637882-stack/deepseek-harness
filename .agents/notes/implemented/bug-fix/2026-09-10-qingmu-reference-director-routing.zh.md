# Agent Note：导演修改沿用已存引用草稿

Status: implemented

[English](2026-09-10-qingmu-reference-director-routing.md) | 中文

## 问题

已交付导演预设描述了 PromptIR 建议流程，却没有点名已有引用草稿工具。机位或表演要求可能因此形成另一份建议，没有修改拍摄工作区实际使用的草稿。连接检查也只核验六个旧工具，即使缺少引用读取、预览或保存工具，仍可能显示已挂载。

## 决策

表演、机位和素材引用修改优先读取已有引用草稿，预览准确编译文字，并通过已有 Writer 命令保存用户明确要求的修改。未修改的文字和引用保持原样。正式台词替换仍先走剧本 ChangeSet 工具，再核对引用草稿；只修改引用文字不能证明剧本已更新。镜头来源变化时重新读取上下文和方法，不能给旧文字换一个新哈希。读取失败不代表没有草稿。

连接检查在已有六项要求之外加入引用草稿的三个工具。它仍只检查注册情况，不调用模型、不写草稿，也不证明 Provider 健康。PromptIR 字段建议与缺失草稿的首稿流程保留原路径。

## 备选方案

新建编辑服务或自动同步会重复已有草稿路径，也可能覆盖浏览器尚未保存的输入。本次将预设接入现有读取/预览/保存工具，保留工作区显式恢复。将全部可选工具都列为连接要求，则会让无关能力阻塞本流程。

## 影响

引用编辑器和导演助手共用一份已存草稿。用户继续控制浏览器未保存输入、素材采用和生成。本次没有修改数据库、生成授权或素材选用。

## 测试

可运行的免密钥原生示例对实际预设及必需工具输出建立快照。真实预设与循环的组装测试检查模型可见路由，验证表演修改保留引号内原台词，并逐项验证缺少引用工具时不会显示已挂载、不会产生 I/O。既有回归覆盖过期版本、切镜和保存响应不明后的回读。该组装中的外部模型回复与 Writer HTTP 仍为脚本响应，不证明真实模型会自主选对工具、媒体质量或付费生成。
