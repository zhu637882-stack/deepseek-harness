# Agent Note：导演修改沿用已存引用草稿

Status: implemented

[English](2026-09-10-qingmu-reference-director-routing.md) | 中文

## 问题

已交付导演预设描述了 PromptIR 建议流程，却没有点名已有引用草稿工具。机位或表演要求可能因此形成另一份建议，没有修改拍摄工作区实际使用的草稿。连接检查也只核验六个旧工具，即使缺少引用读取、预览或保存工具，仍可能显示已挂载。

## 决策

已有镜头修改先读取并保存完整导演设计，再整理已存引用草稿，通过已有 Writer 命令保存。本地引用可以在上传准备前保存，准备后再预览实际请求。生成稿保留逐句语气、停顿、落实到表演的潜台词、有动机的运镜、动作前提和连续声音。内容对照与来源哈希匹配分别核查，参考用途和剧情需要的画面文字也纳入对照。未修改的文字和引用保持原样。正式台词替换仍先走剧本 ChangeSet 工具，再核对引用草稿；只修改引用文字不能证明剧本已更新。镜头来源变化时重新读取上下文和方法，不能给旧文字换一个新哈希。读取失败不代表没有草稿。

连接检查在已有六项要求之外加入引用草稿的三个工具。它仍只检查注册情况，不调用模型、不写草稿，也不证明 Provider 健康。PromptIR 字段建议与缺失草稿的首稿流程保留原路径。

## 备选方案

新建编辑服务或自动同步会重复已有草稿路径，也可能覆盖浏览器尚未保存的输入。本次将预设接入现有读取/预览/保存工具，保留工作区显式恢复。将全部可选工具都列为连接要求，则会让无关能力阻塞本流程。

## 影响

导演可编写 generationContext，将全片方案落实到当前片段。它只在生成时替代未分镜的全片方案；完整研究来源、新鲜度核对、项目画风和本镜其他全部执行字段保留。全片动作顺序否则可能与后续镜头的起始状态竞争。创作入口要求核对相关世界例外、主体身份、空间、材质、光源和各部门设计，不用关键词过滤决定删什么。旧稿缺少非空该字段时沿用原编译，待导演明确修订。测试覆盖本段生成与完整研究、对白及专项方法、字段类型和旧稿兼容；真实媒体仍需审看。

同一导演保存工具现在可同时提交起始图描述与整镜 `visual` 设计，复用既有规划原子修改和原请求回执恢复；省略起始图字段则保留原文。不再绕到另一条 PromptIR 路径，也不自动重新生成媒体。

常规组装为每个绑定素材接收一项用途，将完整当前生产设计原样放在正文末尾。原生模型无需复述计划或另写一套末尾约束。用途组装与自由手写提示词互斥，两者仍保存到既有网页可编辑格式；旧显式导演正文片段继续支持有意手写修改。复制保留世界例外、全片风格、逐镜决定和对白，相邻镜头研究仍分开提供。保存前核验来源 SHA 和完整结果长度。用途文字及源设计本身的矛盾仍需语义核查，组装不能证明实际观察或生成质量。创作修改继续使用已有导演设计工具，不禁止具体运镜、对白结构或剧本例外。

引用编辑器和导演助手共用一份已存草稿。用户继续控制浏览器未保存输入、素材采用和生成。本次没有修改数据库、生成授权或素材选用。

## 测试

可运行的免密钥原生示例对实际预设及必需工具输出建立快照。真实预设与循环的组装测试检查模型可见路由，验证表演修改保留引号内原台词，并逐项验证缺少引用工具时不会显示已挂载、不会产生 I/O。既有回归覆盖过期版本、切镜和保存响应不明后的回读。该组装中的外部模型回复与 Writer HTTP 仍为脚本响应，不证明真实模型会自主选对工具、媒体质量或付费生成。

原生素材目录同时传递记录中的音视频时长与 Wan 3 引用限制，未知时长保持未知。导演可在总时长额度内安排多份音色样本；不增加单说话人规则，也不自动删除必需对白。网页显示同样的时长元数据，素材准备仍由原文件检查决定。

本镜方案读取为保持回执大小可控，不包含完整全片方案，并明确指出已有引用草稿读取才提供当前完整全片、世界和资产来源。写入非空继承设定必须已有该来源的成功读取，并在提交前再次核对；已提交结果的恢复不要求新来源。这样避免缺失当前资料时静默采用会话旧描述；创作内容中的矛盾仍须导演检查。

丰富的已存导演稿同时出现在上下文快照和规划行时，重复副本会超过单次读取上限。模型视图只省去与完整规划行或其导演设计完全相同的上下文字段；不同值保留，原回执与来源身份完整。原生组合检查在实际落盘阈值下，通过普通工具保存并重新打开丰富导演稿。

绑定图片的读取同时返回 JSON 和图片附件。回执读取器识别该日志结果，使成功读取的当前全片来源能够用于后续导演保存；额外文字、失败、调用不匹配和已变来源仍被拒绝。实际组合回归同时验证带图读取后保存成功，以及同样读取后来源变化时不写入。

手动分镜编辑器此前在原生导演已保存新拍摄设计后，仍显示回执绑定的初始规划稿。现在按镜头身份读取当前创意字段，原结构文字保留。已提交修订刷新未改副本，不替换未保存或待恢复输入。明确的当前稿编辑会应用所给创意字段，包括恢复原规划值；旧请求保持原比较行为。自动分镜通过已有编辑操作使用同一完整编辑器。回归覆盖清空值、专项部门、对白来源、原生刷新、断线恢复和恢复原值。

新的自动准备采用[共用拍摄执行创作](2026-09-15-qingmu-shared-execution-prompt.zh.md)；本文描述的整份来源复制保留给旧调用和手工编辑。
