# Agent Note: 青木批量恢复与连续性观察

Status: implemented

[English](2026-09-15-qingmu-batch-recovery-continuity.md) | 中文

## Problem

关闭标签页会丢失已授权批次的剩余命令。复用有效草稿可能漏掉修改意见。整片声音报告没有检查剪辑点两侧的画面连续性，界面也过早展示了详细设置。

## Decision

现有批量命令保存在 localStorage，通过浏览器 Web Lock 协调提交。恢复沿用原请求编号，冲突的旧记录继续保留。修改意见使报价失效，并进入待生成或明确重做范围内的新请求。其他页面已改稿时不覆盖，相同已存请求在准备失败后继续复用。

现有整片检查接口接收带版本的音画检查要求。连接处检查需要两侧观察，缺少依据保留未确认。旧声音报告与排队请求继续使用原方法。四步导航保留原有链接，将素材与分镜放入准备步骤；逐镜详细设置按需展开。

## Alternatives considered

**新增队列或导演框架。** 服务端幂等和审片任务已负责这些工作，再加一套会增加恢复复杂度。

**收到意见后重生整集。** 这会越过选定范围，并可能替换可用成果。

## Consequences

恢复限同一浏览器配置，不跨设备。Web Lock 需要支持的安全浏览器环境。报告是模型观察，不是验收；缺少剧本或身份参考时结论受限。这些修改本身不生成图片或视频。
