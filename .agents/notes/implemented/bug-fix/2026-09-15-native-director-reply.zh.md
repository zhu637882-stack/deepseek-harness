# Agent Note：原生导演回复可见性

Status: implemented

[English](2026-09-15-native-director-reply.md) | 中文

## 问题

镜头输入框接收普通表演要求后，仅展示结构化台词修改进度，已完成的导演回复在工作台不可见。

## 决策

通过已有只读原生历史接口展示本项目导演最近回复。明确显示处理中与失败，导航后丢弃迟到读取。查看不会重发要求或保存创作数据。

## 考虑过的替代方案

**另建导演执行通道。** 没有必要，原生会话已经持有结果。

## 后果

回复和会话界面的九项聚焦测试通过。面板标注为导演最近回复，不表示当前镜头审核通过。运行验证与作品审看分别进行。
