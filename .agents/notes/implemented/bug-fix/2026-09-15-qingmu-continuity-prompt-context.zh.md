# Agent Note: 青木批量准备中的连续性上下文

Status: implemented

[English](2026-09-15-qingmu-continuity-prompt-context.md) | 中文

## Problem

批量准备只向导演提供尚缺草稿的镜头。已有镜头可能确定了不同的地点或人物状态，却没有进入该请求。请求还将已保存设计视为已经协调，允许引用用途与设计发生冲突。

## Decision

批量请求包含全部镜头，并明确标记需要准备的镜头。现有解析规则仍只接收缺失草稿的输出。共用引用指令核对可见演员、机位所在侧和道具图内容与已存设计，不建立第二套生产提示词。剧本与素材指令在来源处处理场景动作前提和独立复用道具。原生导演角色在真实装配中承担同样的职责。

## Alternatives considered

**仅向视频文本追加否定要求。** 这会保留矛盾动作和误导参考图。

**批量准备时改写或重新生成已有镜头。** 这会扩大当前操作范围，并在未经创意认可时替换作品。已有镜头只作为上下文。

## Consequences

导演获得更多整集上下文，并负责判断来源是否一致。这不是确定性的视觉质量保证。收取候选会刷新既有审看投影，同时保留各镜登记失败。组件请求快照与真实预设的免密钥原生运行快照验证指令传递；创意效果改善仍须审看重新获准生成的媒体。
