# Agent Note：青木导入台词连续编辑

Status: implemented

[English](2026-09-10-qingmu-imported-dialogue.md) | 中文

## Problem

已确认的导入剧本以 `sourceLineId` 标识台词。镜头投影丢失这个编号会阻断原生精准修改。台词保存还会改变剧本哈希，因此不能仅凭与不可变分镜初始来源相等，判断后续结构编辑是否可执行。

## Decision

Writer、读取适配器和 IMAGO 方法编译器共用明确的已关联、未定时台词类型。既有原生台词命令接受唯一明确的剧本编号，原子更新剧本和帧副本，使依赖媒体与提示词失效。原生会话继续执行前核验权威新来源再重绑。引用草稿保留原来源，要求明确修订。

场景规划保留初始来源回执。只有重放连续且精确的纯台词 ChangeSet 链、验证每份存储载荷、命令回执和 outbox，并核对当前帧副本后，才允许后续剧本继续编辑分镜。当前剧本版本和哈希仍是命令的并发前置条件。回执损坏返回结构化完整性错误；无关剧本修改仍作为冲突拒绝。

## Alternatives considered

**为导入台词虚构时间。** 文本编号不能证明说话时序。

**用最新剧本哈希替换分镜初始来源。** 这样会抹去血缘，也可能允许无关的剧本替换。

**另建台词数据库或恢复队列。** 既有 ChangeSet、回执、快照和原生会话事件已承担这些职责。

## Consequences

关联的 Writer、Harness 和 Core 消费方须配套生效。重复或冲突编号仍明确报错。修改保留来源元数据与引用顺序，不批准媒体、不启用 Provider 请求。

## Testing

可运行的免密钥原生示例通过随包预设记录真实导入台词读取和预览。真实临时 Writer 服务覆盖连续修改、响应恢复、帧传播、旧引用拒绝、手工分镜继续编辑，以及 HTTP 回执损坏拒绝，全程无生成任务。独立适配器和编译器测试核验编号保留并拒绝虚构时序。这些检查证明工作流行为，不代表模型质量或人工创意验收。
