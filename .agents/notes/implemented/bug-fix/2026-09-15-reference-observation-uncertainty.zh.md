# Agent Note: 参考图观察的不确定性

Status: implemented

[English](2026-09-15-reference-observation-uncertainty.md) | 中文

## Problem

真实整集准备中，视觉观察员将挂墙木板称为封闭窗户，导演随后选回了招生牌位置已知有误的旧院落。素材目录包含全部版本，问题出在解释和比较，并非目录漏项。

## Decision

观察员区分可见结构与用途推测，包括难以确定的木板和开口。批量选择对照修正目标、残留缺陷和新增缺陷比较各版本；不能仅凭推测的名称退回已知有错的旧版。现有包含提示词的观察摘要标识会阻止复用旧指令下的观察结果。

## Alternatives considered

**总是选最新图片。** 新图可能引入其他缺陷。

**硬编码某项目的选定图片。** 无法改善下一个项目的选择。

## Consequences

桥接与批量准备的聚焦测试及更新后的请求快照通过，共116项。这些指令改善证据处理，但不保证视觉判断或生成连续性；实际改进后的整集方案仍需在提交前检查。
