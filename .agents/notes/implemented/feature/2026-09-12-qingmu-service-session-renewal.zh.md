# Agent Note: 青木原生服务会话续期

Status: implemented

[English](2026-09-12-qingmu-service-session-renewal.md) | 中文

## Problem

本机 API 令牌到期会阻止读取和保存项目。为加载新令牌重启 Host 会中断原生导演会话，并让普通恢复依赖终端操作。

## Decision

原生启动器在启动及到期前，通过既有登录 API 为专用账号续期，先验证实例与认证用户，再原子保存令牌。两个适配器共用每次操作读取私密会话文件的方法。原生登录保留 Host；旧前端登录保留 Cookie 与进程刷新流程。时序和恢复细节统一记录在[启动器指南](../../../../docs/cookbook/qingmu-local.zh.md)。

## Alternatives considered

**到期后重启**会中断活跃会话。**长效令牌**只是推迟到期，未解决恢复问题。**401 后重发**可能重复执行结果未知的命令，因此认证恢复与回执恢复分别处理。

## Consequences

管理进程负责续期，无额外守护进程，也不向浏览器传令牌。登录失败后退避重试，保留草稿、回执和进程。会话文件缺失或不安全时不回退到旧环境凭据。该机制只恢复服务认证，人工审核身份和付费指令授权仍分别验证；已移除或失效的登录凭据仍需修复。

## Testing

生命周期测试覆盖到期、启动、退避、身份不符、状态保留与旧模式。Loader 组合测试在同一读写处理器仍挂载时替换私密文件，验证随后预览和保存使用新认证，认证失败不重发，文件缺失不回退。原有预览快照保持不变。
