# Agent Note: 青木参考图像检查

Status: implemented

[English](2026-09-12-qingmu-reference-image-inspection.md) | 中文

## Problem

原生导演能够读取素材描述，却无法查看实际参考像素。仅凭描述不能确认可见服装、灯光数量或道具朝向，还可能沿用过时的视觉安排。

## Decision

参考工具通过目录页、素材 ID 和 SHA256 读取当前项目的一张图片。既有读取适配器验证本地签名媒体地址；工具核对源文件，复用附件服务存图，并为支持图像的导演返回写入会话日志的图片结果。文字导演通过同一个 LLM 服务调用显式配置的视觉观察员，保留原来的主创模型。观察员接收真实附件，输入、观察与用量均写日志，未变化的成功观察会复用。下载前验证模型支持图像输入；选择改变时丢弃迟到结果。预设要求区分观察与推断，并复用仍在上下文且没有改变的图片。

## Alternatives considered

只提供文字会保留看不到图的缺陷。任意网址或文件读取会扩大访问范围。将 base64 写成文本既重复字节，也绕过既有持久附件机制。另一套素材库会重复存储与模型投影能力。

## Consequences

必需的观察事件纳入生成的运行时持久事件清单。回放测试检查发出的每种观察事件均允许冷启动读取；重启后再通过普通网页验证既有日志恢复。检查需要可用的附件存储及明确支持图片输入的主模型或已配置观察员。观察员只执行一次有时限和输出上限的 prepared call，不自动重试；不完整输出明确失败。报告是注明来源的建议，主导演不能冒称自己直接看到了图片。源文件哈希标识素材，附件引用标识其规范化图像。查看不批准、选用或重新生成媒体；模型图片输入按正常模型额度计费。单个视角不能证明隐藏结构、物理尺寸或全片连续性。

## Testing

已交付 YAML 预设通过 Loader、真实适配器、智能体循环和本地附件服务运行。不需要密钥的快照包含图像结果，后续模型请求引用同一持久图片。失败用例覆盖错误素材、哈希、音频条目、不支持的模型、无效媒体、尺寸限制及切换选择。文字导演组合还验证观察员收到真实图片、主导演收到注明来源的文字、结果复用、不完整输出及切换后的迟到结果。真实模型理解效果与传输验证分别判断。

视觉观察路线采用 Qwen3.7 Plus 快照，复用现有 pi-ai 适配器及各 home 的供应商设置，不新建传输或供应商框架。真实 DeepSeek 视觉别名试验误识别零件托盘及电线连接面，因此能够接收图像不等于适合承担导演观察。

前置创作请求将当前项目和分集写入独立的持久用户消息块。素材与整场导演通过 qingmu_read_asset_design 读取已保存设计和分页图片目录，再复用 qingmu_view_reference_image 看图，无需先绑定镜头。范围来自工具所在轮次已消费的唯一用户请求，不从模型参数、旧聊天或后续排队输入推测。既有逐镜读取保留选择检查。两个阶段复用相同的媒体、哈希、附件和视觉路线，不新增素材库或生成入口。读取已存设计不覆盖用户请求中更新的未保存内容；看图不选用候选。
