# Agent Note: 青木参考图像检查

Status: implemented

[English](2026-09-12-qingmu-reference-image-inspection.md) | 中文

## Problem

原生导演能够读取素材描述，却无法查看实际参考像素。仅凭描述不能确认可见服装、灯光数量或道具朝向，还可能沿用过时的视觉安排。

## Decision

参考工具通过目录页、素材 ID 和 SHA256 读取当前项目的一张图片。既有读取适配器验证本地签名媒体地址；工具核对源文件，复用附件服务存图，并返回写入会话日志的图片结果。下载前验证模型支持图像输入；选择改变时丢弃迟到结果。预设要求区分观察与推断，并复用仍在上下文且没有改变的图片。

## Alternatives considered

只提供文字会保留看不到图的缺陷。任意网址或文件读取会扩大访问范围。将 base64 写成文本既重复字节，也绕过既有持久附件机制。另一套素材库会重复存储与模型投影能力。

## Consequences

检查需要可用的附件存储及明确支持图片输入的模型。源文件哈希标识素材，附件引用标识其规范化图像。查看不批准、选用或重新生成媒体；模型图片输入按正常模型额度计费。单个视角不能证明隐藏结构、物理尺寸或全片连续性。

## Testing

已交付 YAML 预设通过 Loader、真实适配器、智能体循环和本地附件服务运行。不需要密钥的快照包含图像结果，后续模型请求引用同一持久图片。失败用例覆盖错误素材、哈希、音频条目、不支持的模型、无效媒体、尺寸限制及切换选择。真实模型理解效果与传输验证分别判断。
