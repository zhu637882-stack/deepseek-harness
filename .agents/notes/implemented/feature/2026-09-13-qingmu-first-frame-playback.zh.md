# Agent Note：青木首帧候选显示

Status: implemented

[English](2026-09-13-qingmu-first-frame-playback.md) | 中文

## Problem

原生会话可通过 Host 鉴权读取任务状态，但浏览器图片元素无法附带该服务凭据。因此，即使生成成功，无签名的 Writer 媒体地址仍返回 401。

## Decision

Writer 核对项目和任务范围后，用现有的限时媒体访问机制为已落盘候选的媒体 ID 签名。命令适配器只接受包含单个有效期和签名的相对媒体路径，再限定到配置的 Writer 地址。回读同一请求即可刷新链接，不提交新任务。座舱在刷新父页面前，将候选显示通知记入对应的已保存请求；重新挂载恢复图片，不再次通知刷新。新请求仍独立触发更新。

## Alternatives considered

将账户令牌交给浏览器会暴露无关账户权限。另建媒体代理会重复视频候选已有的签名播放机制。

## Consequences

候选预览无需本人 Cookie。媒体签名不授予创意批准或正式选用。测试覆盖签名绑定、有效期和适配器地址限制；真实浏览器验证图片解码与项目恢复。
