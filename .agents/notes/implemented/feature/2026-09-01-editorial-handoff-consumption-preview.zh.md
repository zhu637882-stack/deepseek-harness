# Agent Note：复验已下载剪辑交接包并提供消费预览

状态：已实现

[English](2026-09-01-editorial-handoff-consumption-preview.md) | 中文

## 问题

浏览器成功下载只证明当时返回的字节，不能证明稍后重新选择的本地文件仍是同一份包，也不能证明原生 OTIO 消费者仍能解析轨道与媒体引用，更不能证明其项目、剧集、来源快照及投影仍是当前版本。

## 决策

Host 从 Writer 认证用户的成功下载终态派生一次性导入 capability。浏览器只能重新选择 ZIP，不能提供受信身份、包 SHA、大小或来源坐标。Host 把上传流式写入私有 DSH home 下的 0600 文件，精确核对终态大小和 SHA-256 后，才通过域分离的 Host HMAC 继续流式发送给新的 Writer 认证只读复验器。专用密钥按实例私有、restore 时轮换，缺失或过短时失败关闭。上传中断会清理暂存；启动时只删除本功能具名的孤儿目录。

Writer 复用 canonical 包复验器，以分块方式校验精确归档清单和每个条目摘要，解析原生 OpenTimelineIO 0.18.1 JSON，并把 Picture／Dialogue 轨道、镜头顺序、来源区间和相对媒体引用绑定到 manifest。另一次当前投影读取独立报告这份内部有效的包是否仍匹配当前项目与剧集权威。来源漂移既不会变成包损坏，也不会被包装成通过。

导演台把下载回执匹配、包内有效性和当前权威匹配显示为三项独立结论，并展示轨道与镜头摘要，但不打开 NLE。成功终态预览可在刷新或重启后通过新签发的同范围 capability 恢复，无需重新上传或再次联系 Writer。失败时浏览器保留用户已选文件，等待显式重试。

## 验证

Writer 测试覆盖 Host 服务认证、原生引用自签改写、归档篡改、owner 与范围、精确回执字节及当前来源漂移。Host 测试覆盖服务凭据缺失、改字节或截断、登录与范围变化、一次性恢复、Host 重启和孤儿清理。UI 测试覆盖三项独立结论、保留输入、终态状态恢复，以及刷新或范围变化后拒绝迟到的导入响应。构建后的青木 Host、真实 FastAPI 与 Chromium 纵切完成下载和重选、预览双轨、重启 FastAPI、在全新浏览器上下文恢复，并确认夹具数据库 SHA 与 storage 文件树不变，外部请求为零。

## 考虑过的替代方案

**信任浏览器计算的摘要。** 未采用，因为浏览器不能声明回执 SHA、认证身份或来源坐标。Host 改为从已认证的成功下载终态派生全部权威，并独立流式读取和哈希用户重新选择的字节。

**由浏览器直接上传给 Writer。** 未采用，因为这会暴露特权 Writer 凭据或扩大浏览器 API。窄化的同源 Host 接缝把认证和一次性绑定留在浏览器合同之外。

## 后果

这只是只读剪辑消费预览，不打开 NLE、不确认制作完成或发布就绪，也不推断人工签收。媒体容器校验仍是有界检查，不是完整独立解码。中央目录与 ZIP64 头部细节尚未在 Python ZIP 解析器及既有确定性 envelope 检查之外另行锁定，祖先目录替换 TOCTOU 也仍是后续加固项。
