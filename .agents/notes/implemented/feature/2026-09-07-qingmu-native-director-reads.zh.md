# Agent Note: 青木原生导演读取

Status: implemented

[English](2026-09-07-qingmu-native-director-reads.md) | 中文

## Problem

把 DSh 会话绑定到 Writer 镜头只记录其身份，不会把镜头创作输入交给模型。 方法注册和来源哈希同样不提供 IMAGO 的真实导演方法正文。助手可能看似接通， 却没有提出有效建议所需的依据。

## Decision

在导演上下文桥中增加可选、限定作用域的 `model-tools` 入口。它通过现有 Host 命令适配器读取绑定的 Writer 快照，通过 IMAGO 方法适配器读取完整 C 或 C5 Skill 正文与直接参考。C5 的第四参考可用固定资源 ID 追加读取。模型不能选择 其他会话、对象、文件路径或方法根目录。

复用原生工具注册表与 Agent 循环。普通工具结果把准确返回的 JSON 保存在原有 会话日志并送入下一轮模型请求；绑定事件仍仅记录日志。每次读取前刷新上下文， 切换作用域后拒绝迟到结果，失败时保留手工编辑。来源哈希标识方法字节， 不授予业务或创意批准权。

Writer 仍是业务真源，Core 仍是方法来源。不复制项目，不新增数据库、控制器或 Agent 循环。本次实现的是源码级读取能力，不等于部署或完整创作流程。IMAGO 用于场景意图、表演、调度、连续性和声画推导，不被缩减成提示词格式库。

实验性青木组合包携带 `qingmu-director` 预设，包含完整创作角色提示与限定作用域的读取/建议工具。通用 profile 加载器解析各已列出组合包内部可选的 `dsh.bundle.agentPresets` 目录；CLI 将其追加到原生预设之后，不让正式应用依赖实验包。青木发行默认选择该模式，但原生用户设置仍可覆盖。已有会话保持记录中的组装。该模式对 Writer 只读，与编程和系统编辑模式分离，不把创作方法扩展为任意文件操作或执行权限。

Host PromptIR 读取器可用时，原生工具获取当前提示词草稿、上下文和完整 C5 方法。另一工具根据成功记录的读取回执提出单字段建议；结果只携带精简来源坐标和原文/替换文字，不重复上下文与方法正文。浏览器读取已记录建议，重新核对来源后明确采用到本地草稿。既有方法检查、预览、保存和 Writer 回读仍是唯一持久化路径；自动分镜不走旧场景规划保存。

原生进入控件复用已有会话和预设 API：只切换空对话、按原导演 ID/cwd 恢复，或获取当前所选工作目录中的空白对话。不重组已开始的普通对话历史。独立只读接口检查运行中 agent（智能体）的实际作用域注册；名称与成功绑定都不够。共享传输的握手变化会撤回状态、丢弃待处理建议并重新绑定选中镜头，不重挂编辑器。迟到的进入操作不会改变用户后来选择的会话。

## Alternatives considered

**把全部技能注入每轮系统提示词。** 这会增加 token，并掩盖实际请求了哪份方法。 显式、完整的工具响应可以回放，也允许 Agent 按需补读必读参考。

**开放通用文件读取或全部 Writer 命令。** 这会在读取边界尚未验证前扩大权限。 固定方法 ID 与会话绑定能提供所需内容，无须业务变更或任意文件访问。

**再建一套编排循环。** DSh 已经持久化工具调用与结果。平行循环会重复恢复机制， 使模型输入更难检查。

**自动替换普通会话，或从预设名称推断就绪。** 已有历史属于原组装，而且没有运行中的 agent 时名称仍会保留。显式进入保留原历史；作用域注册检查只报告当前挂载情况，不声称工具执行或提供方健康。

**复用确定性回放建议，或在建议结果中复制完整输入。** 回放工作单会错误表述原生模型输出。每份建议都复制上下文与方法会重复占用存储和模型输入；来源回执用于定位原先的成功读取。

## Consequences

驾驶舱现在同时支持选中权威自动分镜和旧场景规划镜头的绑定。接受不同对象进入后，在 I/O 前清除旧持久绑定；读取失败或取消保持未绑定，被拒建议和未绑定恢复不能取代正在等待的选择。绑定 scope 的浏览器清理租约避免旧视图清掉新绑定；取消选择或卸载会清除其拥有的绑定，修订变化会重新绑定。空值只清除日志绑定，不删除业务内容。投影读取器与桥须一起交付。浏览器状态区分最近一次上下文同步与真实预设/工具就绪。运行期租约不跨 Host 重启保留；成功持久绑定仍会恢复，浏览器须重新进入才能清理，已持久化空值则保持未绑定。断连清理不作保证。

显式启用的 Agent 能收到真实 Writer 上下文与 IMAGO 方法正文。根作用域和普通 Agent 不会获得这些工具。文本上下文不证明图像质量或全剧理解；缺失事实保持未知。

来源加载器限制文件读取并拒绝指向根外的符号链接；部署仍须在读取期间保持方法树 稳定。512 KiB 的来源包可能超过消费端默认 256 KiB 的序列化响应上限，此时失败， 不截断内容。完整方法正文只在请求时消耗 token。

可直接运行的免密钥示例和 Loader 预设测试加载实际随包导演配置，使用脚本化外部响应，核验角色提示、下一轮模型输入、作用域工具目录、已记录原生建议读取与日志冷恢复；启动器测试核验仅来自当前组合包的根目录组装。组件、桥和 RPC 测试覆盖同会话绑定变化、迟到响应拒绝、人工修改冲突、原生进入、连接代次及建议采用到既有草稿保存/回读。这些检查不能证明真实提供方质量或实际 Writer 持久化。首份草稿、生产启用、真实 Host 重启与生成媒体反馈仍须各自接通业务链验证。建议每次只修改一个字段，需要已有 Ready 基线。
