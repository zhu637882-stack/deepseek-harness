# Agent Note：原生素材设计中的空声音身份

[English](2026-09-14-qingmu-null-voice-design.md) | 中文

Status: implemented

一个真实原生素材候选为场景和道具使用了 `voiceIdentity: null`。客户端接收并保留了素材卡，但 Writer 的字符串合同以 HTTP 422 拒绝了整次保存。失败没有改变已保存项目。

共用设计解析器现在将明确为空的声音身份转换为空文本。省略字段仍单独处理，使增量候选保留已有声音描述。其他非字符串值会在替换素材卡前被拒绝。这适用于原生采用、手动导入和本地草稿恢复；Writer 既有的规范字符串合同保持不变。

## 验证

四个聚焦回归案例在修复前失败、修复后通过：角色、场景和道具的空值在卸载与恢复后仍保留，并以空字符串进入保存命令；数值输入保留原有素材卡且不发送保存。组件渲染的错误具有无键内联快照。当前构建与真实保存、报价证据记录在项目 STATE.md 中。
