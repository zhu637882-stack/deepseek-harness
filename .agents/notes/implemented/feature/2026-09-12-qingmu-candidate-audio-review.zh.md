# Agent Note: 青木候选音画审片

Status: implemented

[English](2026-09-12-qingmu-candidate-audio-review.md) | 中文

## Problem

候选视频能够播放，不代表对白表演和环境底声连续；只检查画面无法听取原始音轨。

## Decision

拍摄页通过现有 Writer 队列和预算提交明确的审片请求。原生审片模型接收原视频和一份核验过的生成时提示词，避免当前设计或静态图指令形成竞争依据；缺少绑定提示词时使用已保存的设计。候选审看先记录带时间的观察再比较；缺失、越界或没有关联观察的视觉证据保留为不确定。供应商原始报告保持原样。GET 恢复已有证据，包括旧报告，不发起提交。方法变化允许用户明确重新检查，不自动安排新任务。证据链接只定位已核验的当前候选并暂停播放。声音检查与可见口型分开，两者都不决定视频选用。

## Alternatives considered

**模型审片后自动采用。** 模型证据不能替代用户对创作效果的认可。

**用提交请求轮询。** 导演设计变化可能造成新的意外付费请求，因此轮询采用 GET。

## Consequences

现有队列继续负责费用与恢复。原生音频理解会增加一次付费请求，也可能无法确认结果；它不证明人类批准或跨镜连续性。聚焦传输与渲染测试覆盖明确提交、只读恢复、范围拒绝和不确定证据。运行中的应用另行验证完整调用路径。
