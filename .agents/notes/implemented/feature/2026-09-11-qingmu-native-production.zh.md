# Agent Note: 青木原生项目生成

Status: implemented

[English](2026-09-11-qingmu-native-production.md) | 中文

## Problem

只绑定单个试验项目的素材连接，无法支持新建项目生成。仅发送心跳的工作进程也无法完成普通工作台提交的请求。

## Decision

原生 API 与既有 Writer 工作进程共用明确配置的项目所有者、凭据指纹和预算窗口。供应商调用预检从实例数据库核对项目所有者。所有新项目共用累计额度，新建或切换项目不会重置费用。工作进程继续使用既有队列、预留、提交和结果入库服务。

## Alternatives considered

逐项目重新绑定实例会阻碍用户独立使用项目库。缺少所有者和预算检查的凭据会让无关任务消耗用户额度。另建队列则重复实现恢复与计费。

## Consequences

原生生产配置与此前试验模式互斥。此项改变本地生成可用性，不改变 DSH 模型调用或创作认可。凭据保持私密，配置变更后 API 和工作进程必须一起重启。既有回执和任务身份保留。

## Testing

聚焦检查覆盖私密凭据验证、API 与工作进程共用设置、普通工作进程启动、跨项目预算耗尽及其他所有者拒绝。真实供应商结果的下载恢复与创作认可分别验证。运行实例的短片验证检查最终网页流程。

新项目绑定 DSH 加载的同一套导演、编剧和摄影方法文件，并校验正文哈希。已有项目保留其保存的方法身份。可运行的免密钥创建示例以快照验证实际 API 与共享预算调用记录。
