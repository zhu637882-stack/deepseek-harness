# Agent Note: 青木导演工作流中的视频引用

Status: implemented

[English](2026-09-12-qingmu-video-references.md) | 中文

## Problem

静态图片无法表达导演需要的全部运动与空间关系。仅接受视频链接也会遗漏实测时长、上传行为和输入视频费用。

## Decision

视频引用共用既有按项目限定的草稿、准备、编译、核价和工作进程提交。Writer 在准备前探测并校验本地片段哈希，分发时再次核对来源。时长保留在供应商请求体之外。视频报价计算输入加输出秒数，Python 与 JavaScript 使用固定小数投影校验。工作区和原生导演保留有序引用，不采用源片或结果。

## Alternatives considered

第二套视频编辑流程会重复草稿和生成控制。仅计算输出会低估付费请求。两种方案均未采用。本次实现要求明确输出时长，不包含自动时长；既有自适应画幅选项保留。

## Consequences

既有图片/音频草稿仍可读取。实现需要真实本地媒体、上传、核价及分发失败检查、原生导演记录，以及浏览器保存恢复验证。检查通过证明集成，不代表生成结果的创意质量。每项来源在复用前仍需审查缺陷。
