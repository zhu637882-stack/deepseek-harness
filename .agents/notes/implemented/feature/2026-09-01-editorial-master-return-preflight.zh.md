# Agent Note：本地剪辑母版回传预检

状态：已实现

[English](2026-09-01-editorial-master-return-preflight.md) | 中文

## 问题

交接 OTIO 包复验通过，并不能证明之后选取的本地母版可读、同时含有画面和声音，或仍属于同一项目、剧集、来源与下载回执。把“选择文件”直接当作正式回传，也会凭空制造剪辑师操作、发布权威和人工签收。

## 决策

Host 只从同一认证用户已经成功的交接包消费预览派生母版预检能力。能力绑定原下载和导入请求 ID、包 SHA 与大小、项目、剧集、来源快照和投影。浏览器字节以流式方式写入 Host 私有目录，最大 32 GiB，并由 Host 独立计算哈希。随后，域分离 HMAC 将这些不可变回执事实与母版 SHA、大小一起绑定给 Writer；浏览器 RPC 不接触 Host 密钥或可信坐标。

Writer 把精确字节流写入当前实例私有暂存目录，核对声明 SHA 与大小，确认当前来源和投影没有漂移，再执行只读魔数、容器和 ffprobe 检查。结果报告时长、画面尺寸、帧率、视频流、音频流和结构化阻塞。可判别的无音频、时长缺失、不支持容器或探测器不可用都会保留为阻塞，不包装为成功。数据库与正式媒体树不发生写入，所有终态都会清理临时文件。

同一回执谱系只有一个规范预检状态。重复读取状态或刷新交接会轮换能力而不创建第二份结果，旧能力失效。成功或失败可跨 Host 重启恢复；被中断的运行态变为明确失败，绝不沿用部分字节。

## 已考虑的替代方案

不把回传文件写入业务媒体树，因为技术探测不等于正式回传或发布决定。不采用浏览器侧探测，因为它无法绑定可信回执或保护服务身份。不复用共享临时目录，因为这会削弱实例所有权和重启清理边界。

## 验证

Writer 聚焦测试覆盖媒体事实、无音频和探测失败阻塞、HMAC 与 owner 绑定、当前来源漂移、字节身份，以及数据库和媒体树零变化。Host 测试覆盖一次性上传、精确 Writer 绑定、终态恢复、不发第二次上游请求和私有暂存清理。UI 测试覆盖成功事实、精确边界提示、保留本地输入和交接包预览前置条件。隔离 FastAPI、构建 Host 与 Chromium 路径使用同一流式和恢复合同，且不调用 Provider。

## 后果

该结果只是技术预检。它不证明 NLE 已打开、剪辑师已消费交接、母版已正式回传、发布 Ready 或人工签收。正式剪辑回传记录、不可变证据冻结、发布 manifest 检查与真实 NLE 观察仍在本切片之外。
