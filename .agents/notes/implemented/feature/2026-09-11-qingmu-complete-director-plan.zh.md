# Agent Note：原生工作台中的完整导演设计

Status: implemented

[English](2026-09-11-qingmu-complete-director-plan.md) | 中文

## 问题

修改机位标签或视频草稿不足以保存完整导演设计。表演、声音、连续性及新增创作字段需要进入同一个持久化规划操作，并保留正式台词身份。

## 决策

原生导演工具读取完整规划响应，通过已有 Writer 场景规划处理器修改创作字段。读取回执绑定当前来源；保存结果不明时，相同请求先恢复原操作，再决定是否写入。验证成功的保存推进当前原生会话上下文，不授予生成或素材采用权限。结构性规划修改保留创作字段及台词表演细节。

## 考虑过的替代方案

**另建设计存储**会分裂项目真源。**只改提示词**不会更新正式导演方案。**固定创作字段名单**会丢失后续专项设计。持久化与并发控制由已有规划操作承担。

## 影响

真实原生组合通过命令适配器验证完整方案保存、来源变化、结果不明恢复与上下文续接。Writer 需要配套完整方案 API 改动。生成前仍需协调新设计与引用正文；持久化和无损传递不能证明语义一致、创作质量或实例已经部署。
