# Agent Note: 青木项目库管理

Status: implemented

[English](2026-09-11-qingmu-project-library-management.md) | 中文

## 问题

创作者开始新作品时，需要找到和整理之前的作品。项目库此前没有展示已保存封面，也没有项目元数据编辑入口。

## 决定

既有命令适配器将限定字段的项目名称与归档更新转发到 Writer 校验项目归属的 PATCH 接口。项目库显示已保存封面、筛选创作中和已归档项目，并在编辑失败时保留草稿。Writer 保留项目内容和创作设定。

复制操作根据当前来源快照创建独立的创作项目。Writer 重新分配主体与镜头标识、重建规划来源，并保留当前剧本、设计和素材选择。媒体文件保持原始生成来源。一个 Store 事务同时提交项目和复制回执；浏览器持久化与回执重放可在响应不确定后恢复同一次操作。剪辑、生成任务与审核历史保留在原项目。

## 考虑过的替代方案

**仅在浏览器归档**会在更换浏览器后丢失，并与项目存储不一致，因此归档复用既有项目状态字段。

**删除已完成项目**会破坏可复用的作品。归档仅整理项目库；打开、编辑和运行任务保持既有行为。

## 影响

不引入新数据库或媒体管线。封面不可用时，优先显示校验归属的参考预览，其次显示名称卡片。参考预览带有标记，不授予选择或媒体批准。适配器、UI 和 API 测试覆盖持久化、范围、无效输入及保存失败；归档不等于取消任务。
