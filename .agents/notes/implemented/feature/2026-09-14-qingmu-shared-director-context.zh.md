# Agent Note：青木导演稿的共用来源

Status: implemented

[English](2026-09-14-qingmu-shared-director-context.md) | 中文

## 决策

为已编写的 generationContext 记录共用来源哈希，跟踪本集世界、有效创作设定、全片导演方案、本镜绑定场景及非场景主体；排除其他场景、其他分集、素材取景任务和媒体回执。画外角色与道具绑定未完全建立时，非场景主体保留为保守依赖。来源一致不等于语义正确或像素连续。

分镜读取显示 current、changed、untracked 或 not_applicable，不修改已保存镜头。已知来源变化的稿件在新的图片或视频准备阶段停止，不进入扣费；原稿与当前全片来源仍可读取。旧稿未记录来源时继续可用并明确标为未核对，不自动迁移或替换素材。新建镜头记录创建时的来源；已有稿件只有显式提交匹配的来源哈希才记录同步。无关编辑或重存不变表单不能解除已变化状态。

分镜页列出受影响镜头，拍摄助手填入可编辑的共用设定同步要求，发送后使用已有导演读取、保存、预览工具。导演需一起核对继承设定、首帧、机位、走位、动作与接续，保留剧本例外。保存命令携带读取当前镜头时的共用来源哈希，由 Writer 在写事务内核对。每镜保留各自的剧情时刻与设计，不声称自动改写全片。

已有场次还可通过原生写作会话统筹整场。请求包含当前每镜完整设计、共用资产及相邻场次接续；候选稿须保留准确的场景、来源哈希和镜头顺序身份。未解决的共用来源问题阻止采用，引导回素材设计纠正。采用后形成可检查的本机稿，不写媒体、不再次调用供应商。明确保存使用现有镜头设计命令，每次回执后沿当前版本继续，保留省略的创作字段与剧本归属。这是一串可恢复的逐镜提交，不是整场原子替换。每个请求先落本机再发出；回执丢失时接续完全相同的幂等请求。来源变化停止剩余保存并保留已提交进度。保留并放弃剩余稿不撤销已提交镜头，也不取消未确认的服务端请求。待保存批次限当前浏览器，已提交设计与原生写作会话仍保存在服务端。

标准镜头与镜头要求两种读取均包含实际保存的时长和完整对白对象。整场协调与原生导演读取使用相同值，不再由旧动作节拍猜测时长。来源行身份、表达方式及其他对白字段完整传递。旧读取仍可用，缺少对白字段不代表该镜无对白。提供这些创作输入不增加协调入口修改时长或台词的权限。

## 验证

Writer 覆盖来源变化、图片与视频准备、只读恢复、过期保存、无关编辑、显式同步和幂等。通过 Loader 组装的原生工具验证读取哈希进入真实保存命令。界面测试覆盖受影响镜头提示、稿件保留及明确发送。运行部署与跨项目证据记入 STATE.md。

整场界面测试覆盖手工/自动分镜保存、完整场次覆盖、未决来源问题、刷新后恢复未确认回执，以及提交之间的共用来源变化。真实写作组件的请求具有无密钥快照；后端仍使用已有验证过的镜头保存路径。
