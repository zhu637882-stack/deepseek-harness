# Agent Note: 本地参考在选择前的资格检查

Status: implemented

[English](2026-08-31-qingmu-local-reference-qualification.md) | 中文

## Problem

本地参考候选即使已经保存权利知识记录，仍缺少既有参考选择事务要求的来源修订和完整性证据。填写 Provider 正式一致性字段会编造证据，而从上传状态直接选择会绕过 canonical 门禁。

## Decision

既有候选服务提供一个认证且仅限项目 owner 的资格检查命令。易梦在同一个 Store 事务中重新读取不可变上传回执、当前落盘字节、精确资产 SHA、当前元素修订/快照和当前权利记录 SHA。它写入确定性的本地来源修订、`local_reference_integrity` 一致性检查、版本化资格信封，以及既有 ChangeSet/outbox/回执记录。结果仍严格限于本地：权利已记录但未核验，正式一致性为 false，没有视觉判断，Provider 调用为零，候选继续保持 `Unselected` 且未批准。

制作台把资格检查呈现为单独的明确动作。结果未知时只保留不可变恢复坐标，并只用 GET 恢复回执。资格成立的候选可以进入既有 IMAGO 预览和认证易梦 `selectReferenceAsset` 提交；提交会重新核对上传回执、字节、资格身份、权利 SHA、修订与快照。人物身份和其他既有选择阻塞继续保持权威。

## Alternatives considered

**在本地填写 Provider 正式一致性标识。** 这会错误声称模型或正式检查器运行过。本地完整性使用独立资格类型，并保持正式一致性为 false。

**上传或登记权利后立即选择。** 上传、权利知识、资格检查、选择和内容批准是不同决定。它们各自保持可见且可独立恢复。

**把资格记录放进浏览器或旁路文件。** 这会建立第二权威并破坏重启恢复。既有易梦事务账本继续是唯一可变真源。

## Consequences

本地 PNG/JPEG/WebP 候选现在无需 Provider 调用即可具备进入明确参考选择的技术资格。字节、权利、修订或快照漂移会失败关闭；重复意图只产生一个检查和一个回执；回滚不会留下部分数据库证据或已选择资产。这不代表法律权利核验、视觉身份确认、正式一致性、PromptIR 就绪、生成质量或人工内容签收。
