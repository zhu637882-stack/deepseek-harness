# Agent Note: 青木无状态工作集推荐

Status: implemented

[English](2026-08-27-qingmu-imago-workset.md) | 中文

## 问题

驾驶舱需要给出一项有用的下一步推荐，同时不能隐藏合法的并行工作。易梦普通工作流完成标记不构成 IMAGO 阶段批准，当前投影也不标识权威 LSU 实例。把这些标记或方法定义当成就绪任务会伪造权威。

## 决策

只读适配器把现有已配置处理器作为可选的 `qingmuYimengRead` 服务提供。每次 `/qingmu-imago-method/worksetMethod` 请求只接收项目与剧集 ID，并重新解析该服务。服务缺失或卸载时，只禁用这项读取能力，不禁用其他 IMAGO 方法，也不引入第二份上游配置。

`SERVICE_WALK_EXEMPTIONS` 明确指定由只读适配器 README 负责说明这个私有接口类型处理器；它不是缺少文档的公开子系统服务，也不是面向模型的工具。

Host 分别对完整规范化工作流和来源修订计算哈希，提供明确的权威不可用快照，并通过 stdin 运行 `compile_qingmu_imago_workset_v2.py`。它独立校验准确输入字节、主体、七份本地规则文件哈希和不可执行的输出边界。编译器进程不接收凭据。仅凭来源指纹不足以绑定状态，因为业务状态变化时该指纹可能不变。

Core 合同携带全部合法工作项及其阻塞、前置条件、责任岗位、仅供参考的依赖层级分组、确定性排序键和一项推荐。权威可用分支使用固定样例验证；当前 Host 只接受没有任务实例或推荐的不可用投影。23 项阶段定义是方法模板，不是项目任务。影子对照只使用纯依赖与锁函数，不调用有状态控制器，也不声称执行等价。

总览把业务状态与方法建议分开，最多突出一项推荐，并保留可展开的合法工作项、模板和哈希证据。请求内投影身份与取消机制会在刷新、主体切换、关闭和来源失败时使旧建议失效。这是一项只读能力，不是任务启动器。

## 考虑过的替代方案

**从普通业务标记推导批准或 LSU 范围。** 这些字段不携带阶段工件、来源、锁或认证审核证据。适配器明确呈现权威缺失，不凭空补全。

**接受浏览器快照或只复用其指纹。** 两种做法都会允许过期状态或调用者提供的状态驱动建议。Host 重新读取现有配置对应的权威，并绑定完整规范化投影。

**调用有状态控制器执行影子检查。** 其普通入口可能调和项目状态。编译器把对照限制在纯依赖与锁函数内，并明确禁止正式激活。

## 影响

驾驶舱获得可追溯的方法建议，不增加数据库、项目 DAG 或批准权威。在易梦导出所需权威之前，当前集成如实显示建议不可用。Core 固定样例通过不构成生产就绪。任何工作集请求都不会写入业务数据、调用付费 Provider、启动 Worker 或签收内容。
