# Agent Note：原生素材设计与生成

Status: implemented

[English](2026-09-11-qingmu-native-assets.md) | 中文

## 问题

新项目可以导入剧本，但素材工作区只能上传参考。初始图片生成仍依赖旧剧本地基路线。

## 决策

原生导演从已保存剧本生成人物、场景和道具卡片，允许编辑后原子保存到现有项目实体及导演设定。精确报价确认后，复用现有预算、预约、工作进程与媒体落库。重新进入页面只恢复原任务。初始化分镜时复用已有同名人物与场景。

## 考虑过的替代方案

另建供应商客户端会绕过共享预算与恢复。仅上传无法完成新项目。把原生 Markdown 技能当旧 JSON 方法解析会丢失当前导演方法。图片来源保留实际设计与方法身份，不虚构模型执行证据或媒体批准。

## 影响

交付页复用现有原生会话与绑定分集的剪辑工具安排声音。独立的导演要求先读取整片剪辑及其素材，再将音轨决定保存为现有可恢复版本。本地存在未保存或未决修改时不能发送，离开前会提醒保存；明确触发的重新读取仍保留本地修改。打开面板不调用模型，没有新增导演服务或供应商客户端。

素材卡片将 `visualIdentity`（主体完整外观、结构与布局）和 `imagePrompt`（本次画面或修改要求）分开保存。修图保留后续分镜沿用的主体设定。旧数据读取保留原描述；旧客户端保存时未传新字段，会保留已有主体设定。明确修改主体设定会保留已选媒体，并使未提交报价失效。设置 `selfContainedImagePrompt: true` 时，导演将本图所需的可见外观、尺度、结构、世界例外与空间关系写齐在 `imagePrompt` 中。主体完整设定和剧情依据保留在素材设计及不可变任务来源中，不整段拼入图片指令。省略或设为 false 时保留旧拼接方式；修改选项使未提交报价失效，界面在画面描述旁提供该选项。

完整画面描述同时启用空间取景时，图片请求使用项目基础画风、完整当前画面、当前站位状态和投影构图。整场陈设与导演总览保留在来源上下文，不再追加为另一份可见物件清单；导演须将本图所需的材质、光影与影调写齐到画面描述。没有空间取景时，共用空间描述仍按原路径传入。报价分别显示素材参考图与空间取景图，提交和投影通过不代表实际画面遵从。

接口要求认证所有者和已保存剧本；剧本或设计改变使未提交报价失效。生成图仍是候选。AI 设计使用现有 DSH 模型账户，图片使用共享阿里预算。原生示例与界面测试覆盖设计采用、报价及只读恢复，供应商画面质量由影片另行检查。

原生素材卡片区分剧本事实、导演推导和世界设定例外。每张图保留相关设计依据、视角，以及最多九张按顺序绑定版本哈希和用途的项目参考；可选框选使用原图像素。万相编辑通过现有任务队列接收这些图片及描述，来源变化使报价失效。修改主体设定保留已选图片并提示比较，生成候选不替换原图。导演写定的场景视角和所需文字保持原意，过长请求明确失败而不截断。参考预览和报价不上传或生成媒体。

真实编剧运行暴露了未绑定的整集创作被误套到已有镜头修改、道具状态前后矛盾的问题。创作请求现明确阶段，角色提示仅在已有镜头操作时要求镜头工具，主导演方法从剧本正文检查动作因果。正式导入仍走已有的可编辑文字与预览流程；此改动不代表自动通过创意验收。

素材设计现从创作时就读取有效创作设定，并在图片提交时沿用。导演方法更新声明精确的兼容前序版本，保留旧项目合同及已选媒体。

第二次真实编剧候选仍用自审说明为遗漏的世界例外辩解，因此增加可选的独立会话剧本复核，复用草稿采用和恢复。复核只收到创作原点及当前正文，不继承原作者关于自身正确性的声明。

此前 Flash 编剧错误曾促使青木采用 Pro 默认值。新创作会话现使用已验证接入的 DeepSeek V4.1 Flash 路线；模型升级不等于剧本质量通过，仍尊重用户已保存的选择。素材完善请求同时收到当前未保存的卡片修改和已保存来源，保留用户调整的引用与世界设定。

素材设计各自保存取景画幅。成片画幅可能裁掉全身定妆，而图片修改通常继承参考图画幅；沿用现有尺寸映射，将可选画幅经报价传入模型快照。叙事设定完整保留供导演使用；导演将本图需要的可见事实写齐后，完整画面模式不将其他剧情状态加入图片指令。已有设计在明确修改前使用自动模式。

场次候选同时绑定素材状态 SHA 和剧本。采用时重新读取已保存状态，因此模型创作过程中修改服装或布局后，旧依据不会静默用于新分镜。异步采用遇到读取失败或冲突时保留原稿。导演要求区分起始静态画面与后续动作，并写明有戏剧动机的运镜路径，不规定每镜必须移动。

场景资产方法明确设计叙事陈设与有意留白，避免笼统的简化构图指令抹掉有意义的背景细节。素材设计将可见决定写入画面描述，理由沿用设计依据，不新增一套场景数据结构。可运行的方法传递及相反场景意图的请求用于验证链路，生成像素另行审看。

没有公网 Provider 地址时，非终版浏览器媒体可以使用带有效期的签名相对路径。读取适配器将该地址解析到配置的本地 Writer，使生成图片可在素材库及区域编辑器显示。公网 Provider 可访问性检查与终版媒体身份验证保持独立。

真实水彩与黑白设计请求暴露了未转义引号和 JSON 标记代码块的问题。素材页恢复原始已完成输出；仅当 jsonrepair 的修改只增加引号转义且保留其他全部字符时才采用其结果。仍由已有字段校验决定是否载入，不推测补全缺失内容。原生采用失败会传回创作组件，不再错误显示成功。

素材卡片可单独保存图片模型，不改变项目默认值。Qwen-Image 3.0 Pro 最多接收三张有序参考；不支持的框选和超额引用会明确报错，不自动删减。直接描述优化与思考由用户明确选择，默认关闭。报价包含参考图输入费用并按最高输出档预留，实际入队保留同一模型、选项及尺寸。切换模型会使未提交报价失效，不生成或替换媒体。

视频画面保存复用项目素材与供应商媒体记录，不另建连续性存储。来源 SHA 和播放时间确定幂等保存；解码完成后原子写入素材，并发请求合并为同一图片。原视频与选用状态保持不变，网页和原生导演工具共享操作。验证覆盖实际时间位置的像素、并发恢复、来源或输出字节变更及正式导演工具组合。

导演设计保存后的续接将当前镜头视为受分镜版本管理的创作数据。要求其内容仍等于保存前快照，会拦住导演自己的成功修改。精确匹配保存回执中的分镜版本时允许该镜头变化，剧本、场景、角色、相邻镜头与参考身份仍须保持不变。正式预设组合验证包含改变后的镜头投影、继续整理生成稿，以及仍会阻止续接的外部剧本、场景和版本变化。

青木导演会话通过预设复用原生 DSH 压缩引擎，共用宿主的 token meter。Web 发行层关闭全局压缩，由各预设负责挂载；青木遗漏会话内引擎，导致真实导演在成功保存草稿后超过模型上下文上限。百万 token 的 Flash 路由还曾在触及 65% 阈值前累积超过 500,000 token。该精确路由采用 18% 触发比例和 32,768 token 最近对话保留预算，减少日常请求随模型容量膨胀的历史，同时保留不可拆分的完整单元；其他路由保持原策略。压缩保留原始会话事件与 Writer 已存内容；重新读取当前创作来源，避免只凭摘要生产。不增加工具结果截短，以免隐藏细致的创作来源文字。改写循环或重置会话会重复建设或丢失连续性。正式预设回归覆盖两个路由，通过实际摘要后恢复有镜头范围的读取，核对完整已存稿不变且没有重复写入。发行默认使用已验证的 V4.1 Flash 路由，保留用户的模型选择。

真实原生读取曾把规划回执当作生成来源摘要，把仍然有效的草稿误报为过期。引用稿工具因此直接比较同一次读取中的两个来源摘要并返回 `sourceAlignment`，缺失值保持未知。规划回执保留原保存合同，并明确其独立用途，避免让模型从文字推断确定性的版本关系，也不削弱保存校验。发货预设检查覆盖一致、变化和摘要缺失，均不写入。

候选读取包含现有的分页 Take 评论，保留完整正文、媒体哈希、时间码或帧锚点以及当前／历史设计绑定。导演选择连续性参考时可以读取已有观察，不把已指出的问题默认为动作已经完成。空评论与读取失败明确区分，历史评论不会丢弃。项目所有者无需另授协作者权限即可记录普通观察；评论不选用或批准 Take。组合测试覆盖准确范围、完整分页、历史与不可用反馈，并确认不暴露认证标识；网页操作与原生读取另做现场验证。

素材补充设计保留省略的世界设定字段，并合并部分空间描述；显式空文字和 null 空间对象仍用于清空。已完成后的新一轮素材或整场设计，使用当前来源建立新的原生会话，原会话保留供恢复。素材候选记录当时的本地来源；采用前来源已变时，保留结果并要求根据当前来源重新设计。场景方法协调世界设定、主体、共用格局、空间布局与本图状态，不把导演估计冒充实测，也不改写剧本台词。这些修改防止来源丢失和旧历史混用；生成连续性仍需实际审图。
