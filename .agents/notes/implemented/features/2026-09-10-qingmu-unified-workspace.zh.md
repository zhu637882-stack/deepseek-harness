# Agent Note：青木统一创作工作区

[English](2026-09-10-qingmu-unified-workspace.md) | 中文

状态：已实现

## 问题

五阶段应用仍堆放着互不统一的表单、配色与运维面板。项目素材没有统一视觉浏览入口，预览地址还错误地假设素材编号和媒体编号相同。

## 决策

复用现有应用框架与业务组件，在整个产品统一导航、页面层级、项目上下文和深色配色。增加项目图片/音色库，分镜页优先展示场景引用。拍摄保留媒体优先布局；交付中的导入、回传母版与归档操作按需展开。手机端保留全部操作入口。预览地址使用 Writer 的真实媒体编号。规划读取成功但未包含当前自动镜头时，结束加载并给出提示，避免永久转圈。

## 考虑过的替代方案

另建画布应用会重复范围、保存和生成控制；只美化引用编辑器则会继续割裂整个青木。因此选择基于现有工作流统一产品框架。

## 验证与边界

聚焦客户端、读取适配器和 Writer 测试覆盖改动。使用当前源码构建的独立完整 DSH Host 和一次性 Writer SQLite 数据，验证五阶段切换、图片加载、真实音频播放、三个引用草稿保存及刷新恢复，没有发起付费 Provider 请求。未替换生产端口。本次是界面集成里程碑，不代表创意验收或全部后端能力已完成。
