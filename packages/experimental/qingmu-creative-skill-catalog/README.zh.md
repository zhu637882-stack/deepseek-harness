# 青木创作技能目录

[English](README.md) | 中文

这个私有实验包为青木 OS 创作设置构建确定、带版本的中文创作技能卡目录。卡片是面向产品的方法，不以仓库或 `SKILL.md` 文件名展示。首版目录覆盖剧作、导演、镜头、视觉、声音和质检。

## 集成约定

调用 `buildCreativeSkillCatalog({ directorAssetsRoot, yimengStylePacks? })`。`directorAssetsRoot` 是现有 IMAGO 方法适配器的 `assets` 目录。可选的 `yimengStylePacks` 只携带现有易梦 `GET /api/style-packs` 边界返回的准确响应字节。准入来源修订、规范快照 SHA-256、源内容 SHA-256、内部许可证引用和只读使用边界均由本包持有。本包不请求易梦，也不新增读取路由。

结果使用 `qingmu.creative-skill-catalog.v1` schema。每张卡包含稳定 ID、中文名称与摘要、类别、版本、方法与内容 SHA-256、来源与谱系、许可证边界、支持范围、输入、输出、冲突、依赖、`defaultOff: true` 和 `zeroProvider: true`。创作设置消费方可以按范围列出或筛选这些卡片，再在其现有权威下记录用户的明确选择。读取目录不会选择或激活卡片。

## 来源与完整性边界

六张内置卡只复用 `qingmu-imago-method-adapter` 已准入的内容行：节拍表、导演手册、镜头计划、参考锚定、声音设计表和质检清单。适配器的注册表、静态阶段卡装配、完整包账本、固定提交、许可证和文件 SHA 仍是来源权威。仓库 ID 和路径只作为可追踪谱系出现，不作为卡片展示名称。

可选易梦投影只接受本包固定的规范 `style-pack-v1` 快照，包括准确的分组标签、风格包版本和竖屏交付字段。它对每个投影风格包做哈希，但不会把提示词片段复制进卡片。未知权威、未准入许可证、重复 ID、无效范围、畸形来源、谱系变更、内容漂移、关系错误和方法 SHA 漂移均失败关闭。规范键排序及固定的类别/ID 排序保证相同字节产生相同输出。返回目录会被深度冻结，避免修改后 SHA 失效。

## 运行时边界

这是纯只读库，不是 Cordis 插件、loader、工作流、命令或 Provider 适配器。它不执行网络请求、数据库写入、资产修改、预算变更、人工批准、模型调用或自动激活。其 invariant 配套文件只登记包所有权；目录构建过程校验全部运行时数据。

## 模型体验

### 目录构建

#### 模型看到的内容

无。`qingmu.creative-skill-catalog.v1` 卡片是本地产品元数据，不是模型工具、提示词章节或会话事件。

#### Token 影响

无。目录构建不增加模型可见 token。

#### KV Cache 影响

无。目录数据不会进入模型上下文。

## 已知限制与延期工作

- 本切片不把目录接入 launcher、客户端 UI、易梦壳层或创作设置。相关消费方须在单独批准的集成中使用公开构建结果。
- 易梦请求认证仍由现有读取边界负责。本包只接收字节；来源身份、修订、哈希和许可证来自固定内部账本，因此调用方声明不能创建新来源权威，也不能公开重许可内部风格数据。
- 首批内置集合为每个必需类别提供一个可用方法。新增来源或修改方法属于带版本的目录变更，必须先进入现有准入和许可证权威。
