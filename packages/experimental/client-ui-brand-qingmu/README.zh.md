# 青木 OS 浏览器品牌插件

[English](README.md) | 中文

这个私有发行插件仅在 `DSH_CLIENT_BUILD_PROFILE=qingmu` 时填充通用的侧边栏标记、侧边栏名称和空白会话主视觉标记。它显示公开产品名“青木 OS”，并使用原创的 Q、播放符号与新芽组合矢量标记。外围一等 `qingmu` 构建 Profile 负责浏览器标题、PWA 元数据、欢迎说明和 Provider 中立的模型引导。若把本插件加载进非青木客户端产物，系统会明确报错，不会悄悄呈现半套品牌。

三个占位者通过同一个声明感知的 slot effect 安装，因此无论插件先于还是后于侧边栏与会话声明方加载都能工作，卸载时也不会留下半套品牌状态。

## 模型体验

无，因为这个仅面向浏览器的插件不注册提示词、Schema、工具、结果或 Provider 路由。

#### KV Cache 影响

无。本包不组装提示词，也不发送 Provider 请求。

## 已知限制与延期工作

- 本包有意只负责三个品牌 slot。标题、PWA 元数据、欢迎文案和模型引导已由外围发行层中狭窄的青木构建 Profile 分支实现。
- 模型设置内会保留真实 Provider 身份；青木不会改写第三方服务名称。
- 当前 PWA 资产是可缩放 SVG；正式安装包仍需补齐各平台尺寸图标与签名资产。
- 在青木发行仓库与发布命名空间锁定前，本包保持私有实验状态。
