### 交付与成像模式

按用户点名的结果选择，不自动扩展为整套图：

- **提示词/设计说明**：交付当前请求的完整提示词、必要锁定信息与资产合同；尚未生成的参考图用空列表并标为计划，不填写虚构图片路径或声称图片通过。
- **实际参考图**：用户要求出图且有可用能力时生成所需图片；单图先交单图，整套资产请求或明确跨视角验收需求才扩展角度。实际看图后记录检查结果，用户批准前保持 pending_review。
- **诊断/局部修改**：围绕给定图或提示词指出可见问题、原因假设和对应修正；保留未点名的身份、风格与状态，不默认重做整套资产。

先锁定摄影写实、三维动画、二维动画/插画或其他用户成像方式，再按本包 [电影画面关系判断](references/cinematic-image-direction.md) 设计画面关系与负向。此参考在设计、改写、诊断时读取；编号/文件查询不必加载。模板中的多格、人物尺度、标准布光和材质纹理均按用途选取，不因模板固定成套、写实或宏大。

## 1. 描述维度表

必填维度：空间类型、时代/地点、尺度、材质、时间、天气、光照、色彩、前中后景深度、固定场景标志。

规则：已确认维度写入资产合同的 locked_features；剧本未写明的美术细节由导演在当前创作授权内设计，标注为导演推导，不冒充剧本事实。只有会改变既定剧情或与来源矛盾的未决项才单独标出。描述按整体空间、功能分区、叙事陈设、材质光影和当前可见状态组织。

### 1.1 叙事美术与场景丰富度

场景先作为人物行动和生活的空间设计，再转成图片描述。丰富度由叙事需要决定，不用物件数量、提示词长度或固定繁简等级评价；空旷、洁净、极简、荒凉也可以是完整设计。

1. **人物与空间的关系**：谁使用这里、做什么、生活或工作多久；年代、地域、经济条件和剧本例外如何体现在可见环境。剧本未列家具清单，不等于只能画台词提到的物件。
2. **行动与功能分区**：围绕剧情安排活动区、操作面、储物区、门窗和通道；只为表演和运镜留出所需净空，不以净空要求清空整个背景。先确定物件属于哪里及为何在场，再补细节。
3. **空间层次与视点**：按本张图的取景选择前中后景、遮挡、光区与画外相连空间。不同机位共享同一布局；局部图不强塞全景。是否增加场次或地点由叙事节奏决定，不为丰富而擅加剧情地点。
4. **有因果的陈设与痕迹**：选择能表现人物习惯、场所用途和剧情变化的具体细节，给出位置、材质与状态。区分仍在使用、暂存、收纳或已经移走留下的痕迹；“有生活气息”“电影感”不能代替这些可见依据。避免将一种场所的旧物、磨损或杂乱套给所有场景。
5. **固定与变化分开**：固定建筑和背景陈设作为跨镜连续性依据；参与表演的关键道具另标尺寸、接口和取放状态；雨、风、灯、窗外活动只写本图可见效果，后续变化交给视频和声音设计。无人空场仍保留叙事陈设，不等于空房。

设计依据记录剧本事实、导演推导、留白理由与连续性关系；本张图真正要出现的陈设、位置、层次和状态必须进入 imagePrompt，不能只留在 designBasis。读回实际生图描述，核对具体设计是否被“简洁、仅保留、无物件、无文字”等笼统句抵消；只有导演明确要求的局部限制才保留。剧本需要的标牌与文字按本剧年代和世界设定设计，不自动删掉。

### 1.2 换机位的几何核对

当换机位涉及画面左右、前后或家具正背面且空间关系难以直接核对时，使用 qingmu_check_camera_geometry：先按当前布局和实际参考图建立同一平面的相对坐标，标明原点、轴向、依据与不确定处；物件 frontDirection 表示其有意义的正面朝向，不是长轴。只改变摄影机，保留固定地标坐标，计算新机位的画面左右、镜头前后和朝向。未知位置或背面不能伪装成测量值；工具不判断遮挡、高度，也不保证图片模型按布局生成。把采用的布局依据保留在 space，把相应取景结论写入 imageStage.camera 和 imagePrompt；分镜则写入 cameraAngle、blocking 与连续性设计。

先用原机位检查坐标假设能否解释参考图；参考图中确实可见的对象若被估算坐标判到身后，不得反过来宣布图片中的对象不存在。重新检查原机位、坐标和物件朝向的依据，保留未知项；计算是给定假设下的推导，不叫“实测”。数次候选机位失败不能推出所有机位都不可能，更不能形成剧本或系统的永久限制。

确定机位后逐项读回同一次计算：位于摄影机前方不等于位于水平取景范围内；物件中心在取景范围外也不证明整个物件都不可见；正面与背面按该物件的朝向区分。将这些结论与最终 imagePrompt、imageStage.camera 相互核对，未建模的高度、尺寸、遮挡继续标为待核实。不要把身后的固定标牌搬到镜头前，也不要用另一个候选机位的结论拼成最终构图。只有实际生成并看过图像，才能评价画面是否遵守设计。

### 1.2 地点身份的可见依据

把时代、地域、空间使用者与维护状态落实成少量可见证据：建筑开间与门窗形制、墙地饰面、家具构造和工艺、织物与固定装饰。人物身份、场所用途与剧本例外一起判断；皇家、普通民居、临时住处可以各有合理的繁简，不用同一套粗墙旧木模板，也不将皇家一律等同满屏金色。写明证据在本机位的位置、层次和尺度，保持活动通道。局部改图后仍检查整张图的地点气质，不能修好一个架子就把不合目标的旧环境整体锁回去。

### 场景的共同物理尺度

以本片人物身高为尺度参照，给主要家具、门窗、通道及参与动作的物品统一尺寸和依据。家具分别考虑整体包围尺寸、桌面/座面离地高度、容纳或通行净尺寸；平面物品给长宽，杆状物给总长和直径，容器区分内外尺寸，折叠/开合说明测量状态。无来源数据由导演作合理估值并标注，不要求用户逐个填表，也不把估值伪装成实测。

稳定尺度写入 space.scale 和相关素材 visualIdentity；采用 sceneLayout 时全部几何换算到同一坐标单位，不能把厘米当米。局部摆放与开合写 imageStage。同一物品跨图、跨机位沿用同一实体尺度，透视只改变画面投影。设计时核对人能坐、脚能落地、手能握、门能过、物品能装入、台面有承重和放置空间；触碰与取放对象共享同一参照，不各自凭“正常大小”猜。审图用人物或固定家具作比例参照，看不到尺度依据时只标待验证，不宣称物理正确。

## 2. 一致性/状态规则

先协调共用来源再生成新视角：对照当前剧本、世界设定、场景主体设定、space、sceneLayout 与本图描述。同一事实有相反旧值时，由导演依据当前剧本与已有设计裁定并同步相关字段，不能把矛盾留给图片模型。仅换机位或补充其他素材时沿用已有固定布局；确需改造房间则记录剧情或美术依据，并更新受影响分镜。已有 sceneLayout 时，详细坐标和数值尺寸以它为同一份来源，space.scale 记录尺度参照和估计依据，world 不另维护第二套房间尺寸。固定结构、门的铰接方式与镜头中的开合状态分开；动作状态放入 imageStage。没有实测资料时仍可完成导演设计，但估计不冒充测量。剧本台词逐字继承，事实栏不混入改写版。

同一场景锁定平面布局、入口/出口、主光方向、固定标志、材质老化程度；按用途选择建立全景、反向建立、关键局部或用于连续性核对的空间图，单图请求不自动扩为整套。

变体规则：服装、受伤、昼夜、损坏等变化使用原编号后缀（如 S01b）并记录变化原因；不得悄然覆盖已审核版本。参考图一经通过资产审门，后续视频只可引用，不能重新发明外观。

## 3. 材质细化库

建筑混凝土/金属/木材、地面颗粒与湿度、植被层次、天空介质、水体反射、雾的密度与光散射。

粗词禁止：高级材质、精致金属、真实皮肤、电影级纹理。每项必须改写为表面结构、磨损、反射、接触或微动态。材质与光源、接触点、重力方向一致。

## 4. 光影规则

主光方向+环境光+阴影方向明确；室内注明实用光，室外注明时段/天气。

标准资产图优先可读性而非情绪滤镜：主体与背景分离、关键细节不被死黑吞没、反射不遮挡结构；风格色彩作为可切换层，不能改变资产真实颜色记录。

## 5. 比例、透视与物理规则

一点/两点/三点透视必须与机位匹配；地平线、消失点和人物尺度不能冲突。

禁止：结构断裂、无承重关系、穿模、悬浮、镜像/重复零件、透视与光影方向相互冲突。涉及手持、穿戴、打开或碰撞时，另交付一张交互校验图。

## 8. 质量检查清单

- [ ] 编号、版本、名称和用途唯一
- [ ] 第1节必填维度齐全或明确待确认
- [ ] 空间用途、人物或事件关系在画面中可读；刻意留白符合导演意图
- [ ] 功能分区、叙事陈设和尺度锚点进入实际请求，没有被泛化的清空指令抵消
- [ ] 陈设支持叙事与前后景关系，活动通道可用，丰富度没有变成无关杂物堆积
- [ ] 锁定特征跨视角一致
- [ ] 主体比例/透视/结构正确
- [ ] 材质可见且符合光源
- [ ] 接触、重量和阴影可信
- [ ] 关键面、朝向、开口/接口可辨
- [ ] 无错误增生的肢体、重复道具或水印；保留导演安排的背景陈设和必要文字
- [ ] 背景不抢主体且能辅助尺度
- [ ] JSON 合同可被下游解析

按交付阶段检查：提示词只验证设计与合同，未生成/未见图片的像素项目标 not_evaluated；实际图片的适用项目失败时为 rework。只有实际参考图通过用户审阅才进入 assets_approved，文本通过不替代看图。

实际审图先与设计逐项比对空间用途、叙事痕迹、布局、层次与留白，再检查比例、结构和光影。若设计已空泛，回到场景美术设计；若设计完整而实际请求缺失，修正编译传递；若请求完整而图片遗漏，针对可见偏差返修。不得因文件成功返回就自动沿用有缺陷的场景生成后续视频；审看身份遵循本包青木适配，不把代理审看写成人类批准。

## 9. 负向提示词

第一层（通用）：畸形、扭曲、多余肢体、错误手指、穿模、粘连、漂浮、重复元素、乱码、水印、低清、闪烁。
第二层（scene）：空间折叠、门窗/楼梯不连通、透视错误、无来源雾光、无尺度参照、固定标志漂移。
第三层（画质）：先按用户成像方式选择。摄影写实排除不符合目标的卡通化、蜡皮、合成渲染感；三维动画、二维动画/插画保留选定风格，排除结构错误、风格漂移或意外写实化。各模式按需要限制低清、遮蔽结构的过曝/欠曝、过度锐化；不一律禁止动画、卡通或真实塑料材质。

十条通用反面案例与三层负向写法详见 `references/NEGATIVE-CASE-BOOK.md`；本节的专属负向与之叠加，不可互相替代。
