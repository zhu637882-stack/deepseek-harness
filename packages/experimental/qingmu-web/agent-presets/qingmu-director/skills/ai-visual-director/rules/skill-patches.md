# Skill 规则补丁库

> 每个补丁对应一个已验证的问题，包含触发条件、错误倾向、正确行为和禁止事项。
> 补丁从回归测试中提炼，编号 R00X。

## R001 科幻题材不得默认机甲化

**触发条件**：故事含太空港/仿生人/休眠舱/空间站/木星/外星/AI/星际，但未出现机甲/驾驶舱/外骨骼/战斗装甲/机器人战斗单位。

**错误倾向**：系统自动推荐「科幻机甲」风格。

**正确行为**：
- 太空/仿生人/AI → 暗黑科幻
- 赛博/未来都市 → 赛博佛学
- 有机甲/驾驶舱/外骨骼关键词 → 科幻机甲

**禁止**：不得在无机甲关键词时推荐科幻机甲。不得在仿生人故事里自动加入巨型机器人。

**发现于**：T03-A 废弃太空港仿生少女
**修复文件**：sub-skills/sub-skills/storyboard/SKILL.md、SKILL.md（推荐引擎表拆分）

## R002 按剧本核对光源的年代与来源

风格迁移要区分调色手法和实物光源。剧本没有说明现代物件的普通古代场景，不因“霓虹感”擅自加 LED 或电子屏；穿越、架空、舞台化或导演明确设计的现代光源，记录其来源并保留。禁止词表不能取代对具体世界设定的理解。

## R003 保留剧情文字，验证实际结果

画面文字、对白与制作标注是三种不同内容。屏幕“提交成功”、错误码、名字、年代、告示和铭文若承担叙事功能，应保留原文、载体、位置、视角与可读时段；不能自动替换为图标、色块或静默。

先核对所选模型的当前文字能力，再检查生成结果的字形、内容和跨镜连续性。确有错误时可选局部编辑、引用正确文字资产或后期跟踪合成；这些是实现路线，不是删字理由。参考卡的说明文字与边框若被误画进镜头，应修复这种污染，同时保留画面世界中需要的文字。

## R004 角色卡默认禁止文字标注

**触发条件**：对所有角色使用 `/character` 生成角色设定卡。

**错误倾向**：角色卡中出现「红色标注不可变细节」+ 负面词含 `no text overlay`，二者冲突。

**正确行为**：
- 出图模式（默认）：所有细节通过光影、对焦、构图对比传达，不叠加文字/箭头/编号/方框/引线
- 导演标注版（仅当用户说「导演标注版」「标注」时）：允许红色标注/编号/文字说明

**发现于**：/character 墨渊角色卡
**修复文件**：sub-skills/character/SKILL.md（拆分为出图模式 + 导演标注版）、SKILL.md

## R005 现实都市狭小空间运镜限制

**触发条件**：故事场景为便利店/办公室/车内/卧室/电梯/走廊等单间面积<20平米的室内。

**错误倾向**：出现「环绕慢旋」「中轴线旋转穿越」「航拍级上升」「穿越墙体」等不可物理执行的运镜。

**青木适配**：依据导演设计、场景几何和相机实际路径判断可执行性。面积本身不决定运镜白名单；环绕、复合运动或特殊视觉穿越按项目风格与拍摄意图设计。下列是可选手法，不是唯一允许的手法：
- 固定机位
- 缓慢前推/后拉
- 水平横移
- 低角度仰拍
- 过肩镜头
- 浅景深变焦

**发现于**：R02 深夜便利店（帧5 极慢旋转推进）
**修复文件**：sub-skills/storyboard/SKILL.md、SKILL.md

## R006 默认推荐使用通用风格名而非品牌名

**触发条件**：故事含桌面宠物/童话/绘本/治愈/手绘/日系日常等元素。

**错误倾向**：推荐名直接使用「Disney Pixar 3D」「Studio Ghibli」「吉卜力」「迪士尼」等品牌名。

**正确行为**：
- `3D动画电影风`（替代 Disney/Pixar）
- `日系手绘治愈风`（替代 吉卜力/Ghibli）
- `童话绘本风`（替代 Disney 2D）
- 品牌名仅在用户说「看全部」或明确指定时展示

**发现于**：R04 蓝色桌面宠物
**修复文件**：sub-skills/storyboard/SKILL.md、SKILL.md（风格名规范）

## R007 角色身份冲突必须输出解释

**触发条件**：角色描述含高位身份词（第一剑修/宗师/剑尊/掌门/前辈/老祖/天下第一/绝世/天尊/剑圣/武帝），但在故事中为后辈/徒弟/儿子等身份。

**错误倾向**：直接强行改写用户描述（如把「第一剑修」改成「天才学徒」），或默认给过低年龄。

**正确行为**：输出【身份解释】块，说明适配方案（天才型青年/陨落后重修/年轻一代榜首等），保留用户原始描述，给用户切换选项。

**触发词**：`第一剑修` `宗师` `剑尊` `掌门` `前辈` `老祖` `第一` `天下第一` `绝世` `天尊` `剑圣` `武帝`

**发现于**：/character 墨渊
**修复文件**：sub-skills/character/SKILL.md、SKILL.md

## R008 一键生成不得自动融合风格

**触发条件**：用户输入 `/storyboard 一键生成 [故事]`

**错误倾向**：系统自动使用风格融合（如「东方玄幻 + 王家卫情绪融合」）。

**正确行为**：一键生成默认使用单一最匹配主风格。只有用户明确说「融合」「多版本」「A+B」时才触发融合。

**发现于**：R01 雨夜古寺（早期版本自动融合了王家卫）
**修复文件**：sub-skills/storyboard/SKILL.md、SKILL.md

## R009 风格迁移必须显性声明锁定范围

**触发条件**：用户说「换成X风格但保持角色」。

**错误倾向**：迁移后剧情事实改变（剧情/关系/冲突结果/镜头数/时长/关键动作）。

**正确行为**：每次迁移必须开头声明：
```
🔒 锁定不变：角色DNA / 剧情事实 / 关键动作 / 镜数时长
🎨 变更维度：色彩/光影/构图/运镜/节奏/表演方式
```

**发现于**：TM01 东方玄幻→王家卫
**修复文件**：SKILL.md

## R010 单镜修改必须保留时间码 + 连续字段自动补桥

**触发条件**：用户说「第X镜 [修改内容]」，涉及天气/时间/地点/角色外观等连续性强字段。

**错误倾向**：时间码漂移，或天气修改不处理前后镜衔接。

**正确行为**：
- 严格保留镜号、原时间码、原镜头顺序
- 天气变更：在修改镜的前一镜末尾插入过渡元素
- 联动微调前后镜相关元素
- 输出连续性提示说明影响范围

**发现于**：第5镜雨改雪（早期版本未处理过渡）
**修复文件**：SKILL.md
