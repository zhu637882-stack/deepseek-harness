# 青木 OS 制作驾驶舱

[English](README.md) | 中文

这个私有实验性 Client 插件在 Harness 侧边栏中加入青木 OS 制作驾驶舱。它读取易梦投影，并为分集剧本以及人物、环境、道具档案提供严格收口、由人操作的 ChangeSet 流程。它绝不提交付费 Provider 请求，也不记录创意审核决定。

## 投影与 ChangeSet 工作流

驾驶舱从侧边栏打开，共有五个标签页：总览、剧本与资产、分镜与镜头、生成与质检、费用与交付。它通过仅限回环地址的 `/qingmu-yimeng` RPC 通道读取 `health`、`projects`、`episodes`、`script`、`workflow`、元素档案和权威参考素材候选。

“剧本与资产”标签会把权威结构化剧本格式化为草稿，并提供统一的人物、环境和道具工作台。界面展示各类型专属权威字段、基础/当前/拟议三方版本比较，以及七组准确影响范围和对应 canonical 影响哈希。准备变更时先创建不可变 ChangeSet，再读取服务端差异预览；这两个步骤都不会修改权威剧本或元素档案。只有预览可提交且用户明确确认当前差异后，提交按钮才会启用。每类元素流程中，浏览器只接受字段精确、摘要为小写 64 位十六进制的 IMAGO 方法证明，并把它与投影及投影哈希原样转发；浏览器不读取证明密钥，也不签发证明。发生冲突时失败关闭，必须重新读取新的权威版本。

同一工作台会先从易梦读取参考素材候选，再允许用户明确选择候选。参考素材选择和返修重生成都会调用真实、无状态的 IMAGO 参考素材方法，随后创建易梦 ChangeSet，并复用现有通用预览与提交路径。Host 使用 `QINGMU_IMAGO_ATTESTATION_KEY` 校验参考素材证明，在调用易梦前剥离方法投影与证明。记录“已选择”不等于人工批准或签收。返修重生成只记录意图：`providerCalls=0`、`workerStarted=false`，不会自动生成，也不会自动选择。任一提交被接受后，客户端必须同时重读权威元素档案和参考素材候选，才能清除恢复标记。

在发送 commit `POST` 之前，浏览器会同步把一条最小、非秘密、按主体分键的恢复标记写入 `sessionStorage`，并立即读回核对。所有标记都绑定准确 operation；参考素材标记还绑定候选资产 ID 与 SHA-256。不识别的标记版本失败关闭。不能证明标记完全一致时不会发送提交。若易梦接受请求后对话框、主体或页面消失，重新打开的工作区只提供显式只读回执查询，绝不重提 commit。恢复回执必须与标记的全部血缘一致；权威回读还必须同时匹配主体、修订号和回执声明的 Host 已验证权威哈希，才会条件清除那条精确标记。参考素材操作还必须完成匹配的权威候选回读。失败或错配会保留标记并继续锁住新编辑。用户可以在明确警告后只丢弃本地标记；该操作不会调用易梦，也不会撤销服务端提交。

工作流视图只接受 Host 适配器产出的 `jason.episode-workflow-projection.v1` 约定。运行身份、项目与剧集范围、来源指纹、阻塞项、状态事实和血缘均以投影形式展示；这些字段都不会变成操作指令。

## 只读工作集推荐

总览只使用项目与剧集 ID 向 Host 请求工作集。方法适配器重新读取现有易梦工作流服务，把完整规范化投影与修订绑定到 SHA-256，再运行无状态 Core 编译器。浏览器不提供阶段批准或编译器快照。

界面最多突出一项推荐，同时保留可展开的完整合法工作集。每项都携带前置条件、责任岗位和仅供参考的依赖层级分组。方法定义、来源哈希、规则文件哈希和仅限依赖与锁的影子对照分别放在详情中。这些只读结果均不会启动任务，也不授予执行、付费或批准权限。

当前易梦工作流不导出 IMAGO 权威阶段证据或 LSU 实例。因此 Host 返回不可用工作集，任务实例为零且无推荐；23 项方法定义是模板，不是 23 项就绪任务。易梦普通业务状态单独展示，不能替代批准。刷新、切换范围、关闭和来源读取失败都会使旧建议失效，即使来源指纹未变也不例外。

## Shot River 与共享镜头选择

“分镜与镜头”标签按权威 `frameNo` 顺序展示 Shot River，不按 ID 字典序或输入数组顺序排序。每张卡片展示时长、对白与已定时对白数量，以及当前参考绑定。选中卡片后，关系详情、Hero Frame 画布和 PromptIR 共用现有易梦故事板 frame ID。选择只存在于临时 React 状态中，不增加第二套 Shot 身份、排序存储或业务写入。

只读 IMAGO 方法接收完整 E5-3 节奏与参考字段。响应的目标、关系快照字段、安全标志或两个固定只读操作与请求不一致时，浏览器会拒绝展示。重复元素必须具有一致的档案与当前参考血缘。Hero/E5-2 明确只接收原有的更窄关系图，保留画布方法与 ChangeSet 哈希约定。

画布编辑继续依次经过 IMAGO 结构检查、易梦提案与预览、明确提交确认。响应丢失后，恢复会按原故事板修订与所选 Shot 坐标执行 GET-only 回执查询，不选择其他镜头，也不重复提交。新的权威修订不会改写这些恢复坐标。

## 只读连续性面板

同一个已选 Shot 通过 Host 的三 ID `continuityMethod` 驱动前后镜头连续性卡片。面板区分当前选中素材、历史审计绑定和缺失证据，不把缺少记录显示为失败检查。明确失败的维度仅展示为待归因线索，不是正式 Finding 或自动返修。锁定义及传播规则可展开，项目锁实例明确不可用。

面板只有重读按钮。来源对象变化、刷新、镜头切换、关闭和读取错误会立即隐藏旧证据；取消与响应身份核对防止上一镜头的迟到结果重新显示。面板不提供 Skill 或 Stage 选择、不保存第二套项目状态、不签收内容，也不创建 Provider 任务。

## 同一镜头的已选视频审核

共享 Shot 同时驱动易梦当前选中视频的纯元数据审核视图。原记录的通过、退回、待审、过期和不可用状态保持分离。保留缺陷类型、备注和已有准确时间点，不发明严重度、责任人、认证审核角色或审核时间。既有记录不是独立的青木或 IMAGO 签收。

界面核对响应三 ID、素材/SHA 绑定、只读标志，以及审核修订与当前可见剧集故事板修订是否一致。镜头、投影、port、刷新、关闭和来源变化都会使旧响应失效。唯一操作是重读；不包含媒体元素、外链、选择控件或批准命令。即使其他候选已经通过，当前未选中素材仍明确显示未选中。

## 显式制作单元范围登记

同一镜头工作区读取易梦已有镜头组及其当前或历史单元绑定。用户必须选择已有组、明确填写单元 ID，并确认所示范围。已绑定组不能重新分配单元 ID。可选组必须与可见分镜修订、镜头主键及展示序号匹配；工作流投影不提供镜头内容哈希，客户端不会补造。方法来自现有 IMAGO 适配器，绑定经现有命令适配器，使用来源 SHA 与绑定修订号/SHA 进行比较后写入。

在唯一一次绑定 POST 前，浏览器存入并读回核对精确十一字段、按单集分键的恢复标记，只包含原坐标、哈希、比较条件和确定性的幂等键。响应不确定时保留标记并阻止新登记。显式恢复只查询原回执，即使当前镜头组、Shot 或方法不可用也可查询。只有核验匹配回执后，才可条件清除原标记并重新读取易梦列表；回执本身不会直接生成界面绑定记录。丢弃本地提示不能撤销事务，重新填写相同意图仍沿用原幂等键。

范围登记不封存计划、不创建生产实例、不批准阶段、不释放锁、不执行返修，也不调用供应商。面板不新增第二套运行时、账本或工作流。

## 同一镜头的人工问题记录

共享 Shot 还提供 Finding 面板，包含八个必须明确填写的字段：时间点、观察到的问题、证据引用、最早责任岗位、责任归因依据、严重度、建议和建议返修范围。IMAGO 提供当前字段与岗位合同，每个值均由用户填写，不默认选择责任岗位或严重度。只有易梦明确提供的 reviewer 能力允许记录。Finding 是绑定已选视频素材哈希、镜头内容与故事板修订的 OPEN 问题，不是批准、选择或返修执行命令。

浏览器先核对问题列表和方法与当前 Shot 是否一致，再启用表单。Host 校验方法证明，易梦重新核对当前主体，并在既有事务账本中原子记录 Finding 与回执。刷新使旧请求失效；切换 Shot 或主体变化会丢弃当前内存草稿。当前媒体或方法插件不可用时仍可读取历史记录，不会把旧记录重新绑定到当前素材。

每条记录的既有详情中提供只读返修准备，不是正式路由。当前已验证方法提供精确匹配的责任岗位及适用范围，并将当前规则哈希与原记录比较，不替换原记录。当前、历史和无法核对的媒体绑定保持分离。阶段实例、已封存计划中的单元实例、审批锁实例及独立正式决定均标注为当前读合同未提供，不能据此断言它们不存在。不会从责任岗位推断发生变化的锁。展开这些详情不创建请求、恢复标记或执行操作。

这些详情还复用已经核验的单元列表，不另发请求。只有项目、单集、镜头主键、展示序号、镜头内容 SHA 和分镜修订都与原 Finding 一致时，才展示范围绑定，并区分当前与历史绑定。该证据不能补齐仍然缺失的已封存计划单元实例或审批证据。

在唯一一次记录 POST 前，客户端存入并读回核对精确八字段、非秘密的恢复标记。标记只含哈希和原操作坐标，不含自由文本证据、凭据或方法签名。响应不确定时，只提供显式 GET 查询原回执；页面重载或当前媒体不可用后仍可查询。回执缺失或错配会保留标记；恢复不重新提交记录，也不改写原主体。清除本地标记是独立且带警告的操作，不能撤销服务端记录。记录问题不会执行返修，也不推断人工签收。

## 安全边界

`YIMENG_API_TOKEN` 与 `QINGMU_IMAGO_ATTESTATION_KEY` 只属于青木 Host 进程。浏览器插件不读取环境变量、`localStorage`、`JWT_SECRET` 或 Cookie，也绝不会接收或渲染这两个秘密。它唯一持久化的是当前标签页 `sessionStorage` 中有界、非秘密的回执恢复标记。只读与命令通道由两个独立 Host 插件承载，并且都只允许回环地址上游。令牌缺失时，驾驶舱会提示用户配置 Host 并重启本地实例。

## 三项相互独立的权力

- Harness 执行权限只允许执行已明确授予的本地运行时或工程动作。
- 预算有效、有剩余额度、`releaseReady` 或 `qualityPassed` 状态都不构成付费 Provider 调用授权。
- 人工接受权属于可核验的认证人工审核；驾驶舱不会批准资产、提示词、首帧、生成媒体或最终交付。

## 模型体验

### 浏览器投影

#### 模型可见内容

无。`jason.episode-workflow-projection.v1` 投影始终留在浏览器界面中；这个 Client 插件不注册提示词、工具 schema、工具结果或其他模型可见上下文。

#### token 影响

直接 token 影响为零，因为投影始终留在浏览器界面中。

#### KV Cache 影响

相互独立。打开、刷新或关闭驾驶舱不会改变模型请求或其可复用前缀。

## 已知限制与延期工作

- 这些有界工作台与 Shot River 不表示整个 Phase 3 或 Epic 5 已完成。付费生成、自动选择或批准、Agent 代签收和生产发布均不属于这些本地流程。
- 工作集编译不会创建缺失的易梦阶段或 LSU 权威。Core 的权威可用分支已有固定样例覆盖；当前 Host 集成有意只开放不可用分支。
- 回执恢复只覆盖当前标签页的 `sessionStorage` 生命周期；显式丢弃本地标记不能证明或逆转服务端结果。
- 剧本流程中，浏览器不复现 Python canonical JSON。Host 验证易梦返回的准确 canonical 字节后只下发 `scriptSha256`；缺少或错配这份已验证哈希时，恢复标记会继续锁定。Finding 与制作单元合同另外只允许格式有效的字符串与安全整数，并使用明确的 Unicode 键排序核对有界 JSON 哈希；该算法不扩展到任意剧本 JSON。
- 匿名健康检查只证明存活；除非返回字段明确说明，否则它不证明生产就绪或发布身份。
- `releaseReady` 既不等于 `verify_episode` 通过，也不等于最终人工签收。
- 插件要求青木构建组合与私有 Host 只读、命令适配器运行在同一个本地 Harness 运行时中。
